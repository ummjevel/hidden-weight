# 응시 지역 전체 환경 이미지 제작 설계

## 1. 목표와 범위

기존 응시 지역의 메인 룸 12개와 비밀방 3개를 실제 2D 횡스크롤 맵으로 구성할 수 있도록
모듈형 환경 스프라이트 세트를 제작한다. 이미지의 조형은
`docs/concept-art/03-gaze-sky-observer-v2-clean-master.png`와
`docs/concept-art/generated/gaze-rooms-v1/`의 룸 콘셉트를 기준으로 한다.

이번 범위는 다음 아홉 묶음이다.

1. 지형 타일 24종
2. 이동 발판 18종
3. 시선 위험 장치 24셀
4. 엄폐 구조물 18셀
5. 승강·수송 구조물 18셀
6. 문·숏컷 구조물 24셀
7. 환경 장식 24종
8. 능력·보상 오브젝트 24셀
9. 환경 VFX 24프레임

플레이어, 적, 중간 보스, 지역 보스, HUD, 룸 배경, 실제 Collider와 Unity 애니메이터 구성은
이번 이미지 범위에서 제외한다.

## 2. 제작 방식

모든 결과물은 동일 격자의 모듈형 아틀라스로 제작한다. 생성 원본은 균일한 크로마키
배경을 사용하고, 후처리한 Unity 적용본은 투명 RGBA PNG로 저장한다.

- 생성 원본: `docs/concept-art/generated/gaze-environment-assets/`
- Unity 적용본: `HiddenWeight/Assets/Art/Gaze/Environment/`
- 각 셀은 독립된 측면 시점 Sprite이며 다른 셀과 겹치지 않는다.
- 애니메이션이나 상태 변화가 있는 기물은 같은 열에서 피벗과 외곽 크기를 고정한다.
- 충돌과 위험 판정은 Sprite 외곽이 아니라 별도 Collider가 담당한다.
- 기존 파일을 덮어쓰지 않고 `_v1`, `_v2` 버전을 사용한다.

## 3. 공통 시각 규칙

- 스타일: 손으로 그린 어두운 고딕 코즈믹 호러 메트로배니아
- 팔레트: 먹색 철골, 푸른 흑색 석재, 저채도 보라, 제한적인 냉청록
- 재질: 젖은 석재, 가는 철창, 낡은 사슬, 안구형 석조·금속 기계
- 실제 발판 윗면은 배경보다 밝은 냉청록·회보라 가장자리를 연속적으로 유지한다.
- 보라 발광은 시선 위험, 홍채 장치, 자각 반응에만 사용한다.
- 냉청록 이중선은 숨겨진 자각 반응 요소에만 사용한다.
- 장식은 발판과 상호작용 오브젝트보다 명도와 채도를 낮춘다.
- 생물성은 홍채·눈꺼풀의 운동으로만 암시하며 피, 살점, 노골적인 점액 표현을 사용하지 않는다.
- 풍경 배경, 캐릭터, 적, 투영 그림자, 글자, 라벨, UI, 워터마크를 넣지 않는다.
- 각 셀은 최소 8%의 안전 여백을 가진다.

## 6. Unity 적용 규칙

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Pixels Per Unit: 32
- Filter Mode: Bilinear
- Compression: None
- Mip Maps: Off
- Alpha Is Transparency: On
- Mesh Type: Full Rect
- 아틀라스 분할은 표의 열·행을 기준으로 동일 셀 크기를 사용한다.
- 정적 장식 SpriteRenderer에는 Collider를 자동 생성하지 않는다.
- 발판, 엄폐, 문, 시선 장치는 별도 BoxCollider2D 또는 PolygonCollider2D를 사용한다.
- 시선 판정 원뿔, 활성 시간, 회전 속도는 `GazeHazard`가 관리하고 Sprite 상태만 동기화한다.
- 자각 반응 오브젝트는 `IAwarenessReactive`, 숏컷 상태는 저장 가능한 게이트 상태와 연결한다.

## 7. 검증 기준

- 최종 적용본 9개가 RGBA PNG이며 네 모서리가 투명하다.
- 모든 아틀라스가 지정한 행·열로 나머지 없이 분할된다.
- 크로마키 색 테두리와 녹색 반사가 남지 않는다.
- 실제로 밟는 표면은 모든 룸 배경에서 연속적인 상단선으로 읽힌다.
- 장식, 위험, 상호작용의 명도·발광 규칙이 서로 구분된다.
- 같은 열의 상태 프레임은 피벗과 외곽 프레임이 고정된다.
- 고정 눈과 회전 눈의 휴면·예고·활성·회복 상태가 실루엣만으로 구분된다.
- G02, G05, G07, G08, G11, G12 배경 위 시험 합성에서 팔레트와 원근이 어긋나지 않는다.
- 16:9 화면에 같은 장식을 세 번 배치해도 반복 무늬가 과도하게 드러나지 않는다.
