> 상위 문서: GAME_DESIGN.md, EMOTION_SYSTEM.md
> 목적: 지역별 레벨 구조, 게이팅 지점, 백트래킹 경로를 실제 레벨 디자인 가능한 단위로 상세화
> 표기 규칙은 GAME_DESIGN.md 0장과 동일

## 0. 전체 맵 흐름 (확정 구조 + 권장안 세부)

```
[시작] 몽환의 우주 (튜토리얼)
   │
   ▼
[1] 잔재(殘滓) — 과거·죄책감 ─────┐
   │  되감기 획득                  │
   ▼                              │ 자각 해금 후
[2] 응시(凝視) — 현재·수치심        │ 백트래킹
   │  숨죽이기 획득                │ (구간 3.3 참조)
   │  ★ 자각(自覺) 해금             │
   ▼                              │
[3] 균열(龜裂) — 미래·불안 ─────────┘
   │  예지 획득
   ▼
[선택] 확장 지역 (기쁨 / 분노) — 균열 클리어 후 자유 진입
   │
   ▼
[엔딩] 거짓 깨어남 → 진짜 각성
```

지역 순서(잔재→응시→균열)는 고정이다 (확정, GAME_DESIGN.md 3.3절). 각 지역은 진입부 – 중간 구간 – 클라이맥스의 3단 구조를 기본으로 한다 (권장안).

---

## 1. 시작 지역 — 몽환의 우주 (권장안)

### 1.1 역할
튜토리얼. 기본 이동·점프·공격을 익히는 구간. 아직 어떤 감정 스킬도 없는 상태로, 오직 "작은 동그라미"의 기본 움직임만 가능하다.

### 1.2 구조
- 짧은 선형 구간 (2~3분 플레이 분량 권장)
- 배경은 별·성운 등 몽환적 이미지, 상호작용 가능한 오브젝트는 최소화
- 마지막에 잔재 지역으로 이어지는 통로 하나만 존재 (분기 없음)

### 1.3 제작 결정

- 튜토리얼 UI는 행동 지점 가까이에 나타나는 맥락형 아이콘과 환경 반응을 사용한다.
- 행동을 한 번 성공하면 아이콘은 사라지고 일시정지 메뉴의 조작 도움말에 기록한다.

튜토리얼의 4개 방 배치, 맥락형 입력 아이콘, 실패 복구, 잔재 전환은
`LEVEL_10_DREAM_TUTORIAL.md`를 제작 기준으로 사용한다.

## 2. 잔재(殘滓) — 과거·죄책감 (권장안)

### 2.1 규모와 플레이 시간 (확정)

- 메인방 12개 + 비밀방 3개
- 첫 주 동선 30~40분
- 선택 콘텐츠 포함 40~50분
- 탐험·이동·환경 퍼즐 65%, 전투 35%
- 일반 적 3종, 정예 1종, 중간 보스 1종, 지역 보스 1종을 첫 제작 범위로 한다

### 2.2 방 연결 요약 (확정)

```text
R01 입구 → R02 애도교 → R03 손바닥 광장
                              ↓
                      R04 하층 폐허 ─ S1 납골당
                              ↓
                      R05 되감기 성소 ─ 숏컷 A → R03
                              ↓
                      R06 손가락 내부 ─ S2 죄인의 심층
                              ↓
                      R07 갈비 곡선교
                              ↓
                      R08 상층 승강축 ─ 숏컷 B → R03
                              ↓
                      R09 상층 고가교
                              ↓
                      R10 손목 감시탑 ─ 숏컷 C → R07
                              ↓
                      R11 후회의 회랑 ─ S3 감춰진 눈
                              ↓
                      R12 기억의 교수대 → 응시
```

방별 지형, 적, 보상, 체크포인트, 숏컷, 재방문 규칙은
`LEVEL_20_RESIDUE_DESIGN.md`를 따른다. 실제 발판 간격, 로컬 좌표, 조우 순서와 실패 복구는
`LEVEL_21_RESIDUE_ROOMS.md`를 제작 기준으로 사용한다.

### 2.3 게이팅 흐름 (확정)

1. R03에서 상층 길과 닫힌 승강기를 먼저 보여준다.
2. 플레이어는 R04를 거쳐 R05에서 되감기를 획득한다.
3. 되감기로 R03 숏컷을 열고 상층 진행에 필요한 구조물을 복원한다.
4. R08에서 R03 승강기를 완전히 연결한다.
5. R10 중간 보스를 처치하면 R07과 이어지는 재도전 숏컷을 연다.
6. R12 보스를 처치하면 응시로 가는 통로를 연다.

### 2.4 백트래킹 예약 지점 (확정)

- R11에는 자각 없이는 완전히 보이지 않는 S3 입구를 둔다.
- 첫 방문에서도 카메라 여백과 벽 너머의 낮은 소리로 공간의 존재를 암시한다.
- 응시에서 자각을 얻고 균열까지 클리어한 뒤 잔재로 돌아오면 열린 숏컷을 이용해
  5~8분 안에 도달한다.
- S3에서 잔재의 최종 스토리 파편을 획득한다.

## 3. 응시(凝視) — 현재·수치심 (권장안)

### 3.1 진입부
- 거대한 눈 모티브 기둥들이 늘어선 회랑으로 시작. 숨죽이기 튜토리얼을 이 구간에 배치
- 첫 "시선" 기믹(고정형)을 여기서 소개

### 3.2 중간 구간 — 게이팅 포인트
| 지점 | 요구 능력 | 비고 |
| --- | --- | --- |
| D. 좁은 틈 | 숨죽이기 (축소) | 순수 이동 게이팅 |
| E. 감시자의 회랑 | 숨죽이기 (은신) | 회전형 눈 3개, EMOTION_SYSTEM.md 2.5절 시나리오 |
| F. 우리(새장) 구간 | 숨죽이기 | 갇힌 존재들을 지나치는 연출 — 대사 없이 서사 암시 (권장) |

### 3.3 자각 해금 지점 (확정 위치)
- 지역 후반부, 가장 큰 눈 오브제 앞 (EMOTION_SYSTEM.md 2.4절)
- 해금 직후 짧은 자각 튜토리얼 구간 배치 권장: 은신 중에만 보이는 표식을 이용한 간단한 퍼즐 1개

### 3.4 클라이맥스
- 지역 최심부: 다수의 관객처럼 늘어선 조각상 사이를 자각+숨죽이기 조합으로 통과 → 균열 지역으로 향하는 통로 개방
- 스토리 파편(3차) 배치 권장 — 감정적 무게가 가장 큰 지역이므로, 이 파편이 서사의 핵심 반전 정보를 담는 것을 권장

### 3.5 상세 제작 기준

- 메인방 12개 + 비밀방 3개, 체크포인트 3개, 물리적 숏컷 3개로 구성한다.
- 일반 적 3종, 정예 1종, 중간 보스 1종, 지역 보스 1종을 첫 제작 범위로 한다.
- 방 연결, 감정 곡선, 시선·숨죽이기·자각 학습 순서, 적과 보스의 경험적 역할은
  `LEVEL_30_GAZE_DESIGN.md`를 제작 기준으로 사용한다.
- 실제 방 크기, 로컬 좌표, 카메라, 적·시선·복귀 앵커 배치는
  `LEVEL_31_GAZE_ROOMS.md`를 따른다.

## 4. 균열(龜裂) — 미래·불안 (권장안)

### 4.1 진입부
- 밝은 파스텔 톤 전환이 가장 극적으로 드러나는 구간. 겉보기엔 안전해 보이는 발판 지대로 시작
- 자각을 켜도 "이상 없음"만 표시되는 것을 플레이어가 직접 겪게 하는 첫 함정을 배치 (EMOTION_SYSTEM.md 3.3절 규칙 체감)

### 4.2 중간 구간 — 게이팅 포인트
| 지점 | 요구 능력 | 비고 |
| --- | --- | --- |
| G. 흔들리는 정원 | 예지 | EMOTION_SYSTEM.md 3.4절 시나리오 |
| H. 부유하는 건축물 | 예지 + 기본 점프 | 이동 발판 타이밍 게이팅 |
| I. 거울 방 (가제) | 예지 | 자각이 완전히 무력화되는 것을 가장 극적으로 보여주는 구간 (권장) |

### 4.3 클라이맥스
- 지역 최심부: 스토리 파편(4차, 최종) 배치. 이 파편에서 "무뎌짐"과 "포용" 관련 메시지(GAME_DESIGN.md 2.1.1절 메모)를 처음으로 텍스트화하는 것을 고려할 수 있다 (결정 필요)
- 클리어 시 확장 지역(기쁨/분노) 입구와 엔딩행 입구가 동시에 개방

### 4.4 상세 제작 기준

- 메인방 12개 + 비밀방 3개, 체크포인트 3개, 물리적 숏컷 3개로 구성한다.
- 일반 적 3종, 정예 1종, 중간 보스 1종, 지역 보스 1종을 첫 제작 범위로 한다.
- 방 연결, 감정 곡선, 예지 학습 순서, 자각 무력화 규칙, 적과 보스의 경험적 역할은
  `LEVEL_40_FRACTURE_DESIGN.md`를 제작 기준으로 사용한다.
- 실제 방 크기, 로컬 좌표, 카메라, 발판 위상·적·복귀 앵커 배치는
  `LEVEL_41_FRACTURE_ROOMS.md`를 따른다.

## 5. 확장 지역 진입 지점 (권장안, GAME_DESIGN.md 5.4절과 연결)

균열 클리어 직후 나오는 작은 허브 공간에 두 개의 문(기쁨/분노)과 엔딩으로 향하는 문을 나란히 배치하는 것을 권장한다. 순서를 강제하지 않고 자유 진입 가능.

```
[균열 클리어] → 허브
   ├── 문 A: 기쁨 지역 (선택)
   ├── 문 B: 분노 지역 (선택)
   └── 문 C: 엔딩 진입 (잔재 백트래킹을 마쳤다면 진짜 마지막 파편까지 회수 후 진입 권장)
```

## 6. 스토리 파편 배치 원칙 (권장안)

- 각 지역 클라이맥스에 1개씩, 총 4개(잔재/응시/균열/백트래킹) — GAME_DESIGN.md 3.3절의 "대사 없이 파편으로 완성" 원칙을 지킨다
- 파편은 텍스트가 아니라 환경 오브젝트·짧은 이미지 연출 위주로 구성할 것을 권장 (결정 필요: 구체적 연출 형식)
- 파편 순서(잔재→응시→균열→백트래킹)가 곧 정보 공개 순서가 되므로, 가장 결정적인 정보(예: 주인공의 정체 암시)는 마지막 백트래킹 파편에 배치하는 것을 권장
- 같은 지역 안의 작은 기억 파편과 지역 클라이맥스의 핵심 파편을 구분한다. 작은 파편은
  선택 탐색 보상이며, 핵심 파편만 전체 진행 조건으로 사용한다.
