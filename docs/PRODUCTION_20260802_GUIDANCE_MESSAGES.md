> 상위 문서: `UI_UX_DESIGN.md`, `LEVEL_10_DREAM_TUTORIAL.md`, `LEVEL_21_RESIDUE_ROOMS.md`, `NARRATIVE_CONTENT.md`

> 범위: 몽환의 우주와 1단계 잔재만. 응시·균열 문구와 공통 UI는 수정하지 않는다.
>
> 문서 상태: 1차 검수안 · 2026-08-02

## 0. 표시 규칙

- 기본 행동은 문장 대신 키 아이콘만 보여준다.
- 안내는 화면 중앙이 아니라 행동이 필요한 지점과 플레이어 사이의 빈 공간에 둔다.
- 실제 행동을 한 번 성공하면 해당 안내는 현재 플레이에서 영구히 사라진다.
- 키 문자열을 이미지나 문구에 직접 쓰지 않고 `InputPrompts`의 동적 표기를 사용한다.
- 새로운 감정 능력만 키와 한 문장의 결과 설명을 함께 보여준다.
- 지역 이름은 감정명을 붙이지 않고 `잔재`만 표시한다.
- 기억 문구는 발견한 사실을 기록하는 짧은 문장으로 쓰고 `NARRATIVE_CONTENT.md`와 동일하게 유지한다.
- 막힌 이유는 가까이 접근했을 때 한 줄만 보여주고, 조건이 해결되면 사라진다.

## 1. 몽환의 우주 — 기본 조작 안내

| 방 | 행동 | 위치·발동 조건 | 표시 | 사라지는 조건 |
| --- | --- | --- | --- | --- |
| T01 | 이동 | 시작 `(3,1)`, 2초 동안 입력이 없을 때 `(5,3.2)` | `{Move}` | 걷기 또는 달리기 상태 진입 |
| T01 | 점프 | 첫 1유닛 턱 앞 `(9.5,3.2)` | `{Jump}` | 실제 점프 상태 진입 |
| T02 | 벽점프 | 굴뚝 입구 `(40,3)`, 벽에 접근할 때 | `벽에 붙은 뒤  {Jump}` | 벽점프 상태 진입 |
| T03 | 대시 | 4유닛 틈 직전 `(57.5,12)` | `{Jump}  +  {Dash}` | 대시 상태 진입 |
| T03 | 공격 | 이름 없는 잔영과 안전 바닥 사이 `(73,12)` | `{Attack}` | 공격 상태 진입 |
| T04 | 종합 | 새 안내 없음 | 없음 | 앞에서 배운 행동을 결합 |

### 1.1 세계·목표 안내

조작 아이콘과 동시에 띄우지 않는다. 안전한 평지에 들어온 뒤 화면 하단에 2.5~3초씩 한 번만
표시하고, 이동을 막거나 확인 입력을 요구하지 않는다.

| 방 | 표시 시점 | 문구 |
| --- | --- | --- |
| T01 | 첫 점프를 마치고 안전한 바닥에 착지 | `이곳은 기억과 감정이 공간이 된 꿈이다.` |
| T02 | 첫 낮은 구간을 지나 벽점프 굴뚝에 도착하기 전 | `지나간 일, 지금의 시선, 아직 오지 않은 걱정이 세 공간을 만들었다.` |
| T03 | 첫 적을 처리한 뒤 | `세 공간에 흩어진 기억을 모으면 이 꿈에서 깨어날 수 있다.` |
| T04 | 잔재 입구 앞 체크포인트 도달 | `첫 번째 공간 · 잔재` / `지나간 기억이 남은 곳` |

### 1.2 몰입 연출

- T01 첫 이동 성공: 꺼져 있던 별빛 한 점이 켜진다.
- T01 첫 점프 성공: 원형 궤도 일부가 플레이어의 이동 방향으로 반응한다.
- T02 첫 벽점프 성공: 벽 먼지가 아래가 아니라 잠깐 위로 흐른다.
- T03 첫 대시 성공: 멀리 있던 손 실루엣이 한 프레임 과거 위치에 잔상을 남긴다.
- T03 첫 공격 성공: 적이 파편으로 흩어지며 일부가 플레이어 뒤 원형 배열에 합류한다.
- T04 문 앞 1.5초 정지: 작은 빛이 플레이어 뒤에 원을 만든다. 텍스트와 수집 UI는 없다.

프롤로그의 이름 없는 첫 기억은 현재 `LEVEL_10_DREAM_TUTORIAL.md` 기준대로 무언 연출로 유지한다.
별도 반복 문장은 후속 내러티브 결정 전까지 추가하지 않는다.

## 2. 잔재 — 진행 안내

| 위치 | 상황 | 표시 문구 | 표시 방식 |
| --- | --- | --- | --- |
| R01 | 지역 첫 진입 | `잔재` | 화면 좌측 여백에 2초, 감정명 표기 없음 |
| R03 | 첫 허브 | 문구 없음 | 가장 낮고 밝은 골드 흔적과 재화 줄로 R04 유도 |
| R05 | 되감기 대상 2유닛 이내 | `{Skill} 홀드` | 대상과 플레이어 사이 월드 프롬프트 |
| R05 | 첫 채널링 시작 | `계속 누르면 구조물이 복원됩니다.` | 하단 한 줄, 최초 한 번만 |
| 일반 조우 | 전투 중 잠긴 문 접근 | `적을 모두 처치하면 열립니다.` | 기존 `BlockedHint`, 열리면 제거 |
| 숏컷 | 잠긴 쪽에서 접근 | `반대편에서 열 수 있습니다.` | 기존 `BlockedHint`, 개방 후 제거 |
| 되감기 대상 | 복원 가능한 상태로 접근 | `되감기로 복원할 수 있습니다.` | 기존 `BlockedHint`, 복원 후 제거 |
| R12 출구 | 보스 처치 전 | `기억의 교수자를 처치하면 열립니다.` | 출구 자체 라벨 |
| R12 출구 | 보스 처치 후 | `다음 지역 · 응시` | 출구 자체 라벨 |

### 2.1 문구와 환경 유도의 경계

- R03, R08, R10~R12 상승 방향은 문구 대신 랜드마크·밝은 외곽선·카메라 여백으로 안내한다.
- 점프할 수 있는 벽과 장식 벽의 구분은 문구가 아니라 은백색 상단선과 벽 먼지로 해결한다.
- 보스 입구에서는 `보스` 또는 `위험` 문구를 반복하지 않는다. 체크포인트, 넓어진 카메라,
  닫히는 입구 실루엣으로 전투를 예고한다.
- 길이 보이지 않는 문제를 메시지로 덮지 않는다. 실제 지형 아트와 충돌 위치부터 맞춘다.

## 3. 잔재 — 기억과 몰입 문구

아래 문장은 잔재 지역의 확정 문구로 사용한다. 감정이나 교훈을 해설하지 않고, 발견한 사물의
상태와 기능만 짧게 전달한다. 전달할 구체적인 정보가 없는 지점에는 문구를 추가하지 않는다.

| ID | 위치 | 제목 | 표시 문구 |
| --- | --- | --- | --- |
| `residue_s1` | S1 | 반복된 형상 | `철망 안에 같은 형상이 반복되어 있다.` |
| `residue_skill` | R05 | 되감기 | `무너진 구조물을 복원한다.` |
| `residue_r11` | R11 | 회랑의 형상 | `벽의 홈마다 서로 다른 형상이 놓여 있다.` |
| `residue_final` | 잔재 결말 | 감춰진 눈 | `벽 뒤에서 거대한 눈이 드러났다.` |
| `residue_core` | R12 보상 | 기억 파편 | `기억의 교수대에서 발견한 파편.` |

### 3.1 표시 타이밍

- 기억 획득 순간에는 제목과 본문만 표시한다.
- 조작 안내, 지역명, 보스 라벨과 동시에 표시하지 않는다.
- 본문을 닫은 뒤 0.5초 동안 플레이어 입력을 공격으로 전달하지 않는다.
- R11 문구를 읽고 R12로 이동하는 동안 새 안내 문장을 추가하지 않는다.

## 4. 이미지 필요 여부

| 요소 | 이미지 생성 | 이유 |
| --- | --- | --- |
| 기본 키 문자 | 불필요 | 키 리맵과 게임패드 대응을 위해 런타임 텍스트 사용 |
| 키캡 외곽 프레임 | 보류 | 현재 월드 텍스트 가독성 QA 후 결정 |

| 벽점프 먼지·별빛 반응 | 선택 생성 | 플레이테스트에서 코드 효과가 약할 때만 생성 |
| 되감기 골드 외곽선 | 기존 잔재 VFX 사용 | 신규 이미지 불필요 |
