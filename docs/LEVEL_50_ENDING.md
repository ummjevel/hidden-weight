## 0. 엔딩의 플레이 목표

엔딩은 컷신을 보는 보상이 아니라 마지막으로 플레이어가 판단하는 구간이다. 거짓 침실에서는
스스로 위화감을 느끼고 자각을 사용해야 한다. 진짜 침실에서는 자각을 반복해 정답 표시를
받는 것이 아니라, 더 확인하지 않고 일어나 창가로 가는 행동이 결말을 완성한다.

```text
세 감정의 흔적을 모음
→ 경계 허브에서 기억 장치 활성화
→ 거짓 침실에서 스스로 의심
→ 자각으로 꿈의 흔적 확인
→ 짧은 잔상 몽타주
→ 같은 침실에서 확인을 내려놓음
→ 직접 일어나 빛으로 이동
```

---

## 1. 진입 조건과 분기 방지

### 1.1 필수 조건

| 플래그 | 획득 위치 |
| --- | --- |
| `HasClearedResidue` | R12 지역 보스 |
| `HasClearedGaze` | G12 지역 보스 |
| `HasAwareness` | G11 자각 해금 |
| `HasClearedFracture` | F12 지역 보스 |
| `HasFinalResidueFragment` | 균열 이후 R11→S3 백트래킹 |
| `HasActivatedFinalMemory` | EH01 기억 장치 |

균열을 클리어했지만 S3를 찾지 못한 경우 엔딩문은 잠그지 않고, EH01의 기억 장치가 잔재의
손 실루엣과 R11의 눈 모양을 보여주어 백트래킹을 유도한다. 상호작용 시 열린 숏컷을 이용한
잔재 복귀문을 활성화한다. 최종 파편 회수 뒤 EH01로 돌아오면 엔딩문이 열린다.

### 1.2 엔딩 분기

MVP는 단일 엔딩이다. 거짓 침실에서 자각을 오래 사용하지 못하더라도 막히거나 다른 엔딩으로
가지 않는다. 20초마다 위화감이 한 단계씩 강해지고, 60초 이후에는 자각 입력 아이콘이 아닌
플레이어 손의 떨림으로 힌트를 준다.

## 3. EH01 — 겹쳐진 경계 허브

### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 34 × 18 |
| 난이도 / 카메라 | D0 / 한 화면 고정 |
| 입구 | W `(0, 4)` from F12 |
| 잔재 복귀문 | SW `(5, 3)` |
| 확장 예약문 | N `(14, 13)`, `(20, 13)` 비활성 |
| 엔딩문 | E `(34, 5)` |
| 전투·낙사 | 없음 |

```text
          [기쁨 슬롯] [분노 슬롯]
               L          L
P ____ [잔재 복귀문] __ [기억 장치 A] ____ [엔딩문] >
#####################################################
```

### 기억 장치 시나리오

1. 중앙 장치 `(18, 5)`에는 세 지역 핵심 파편 슬롯이 이미 빛난다.
2. S3 파편이 없으면 네 번째 슬롯만 비어 있고, 자각 시 잔재 R11의 눈 윤곽이 겹친다.
3. S3 파편이 있으면 되감기로 부서진 외곽을 복원하고, 숨죽이기로 낮은 내부 틈에 들어가며,
   예지로 2초 뒤 정렬될 세 고리의 위치를 확인한다.
4. 마지막에는 자각을 홀드한 상태로 장치 중심을 통과하면 네 흔적이 하나의 원으로 겹친다.
5. 활성화 상태를 저장하고 엔딩문을 연다.

이 순서는 기술 시험이 아니라 기억의 재확인이다. 실패, 쿨타임 압박, 적을 배치하지 않는다.
스킬을 잘못된 순서로 써도 초기화되지 않으며 해당 단계의 시각 반응만 보여준다.

### 완료 검증

- S3 미획득 플레이어가 30초 안에 잔재 복귀문과 연결 힌트를 발견한다.
- S3 획득 뒤 장치 활성화는 60초 이내다.
- 비활성 확장문은 현재 필수 콘텐츠로 오인되지 않게 명도를 낮추고 상호작용 아이콘을 숨긴다.

## 4. 1인칭 전환 규칙

- EH01 엔딩문을 플레이어가 직접 넘은 뒤 1.2초 암전한다.
- HUD, 체력, 스킬 아이콘은 사라지지만 자각 입력 자체는 유지한다.
- 이동은 좁은 침실 안의 느린 걷기, 시점 회전, 자각만 허용한다.
- 카메라 흔들림과 강제 시점 이동을 최소화해 멀미를 줄인다.
- 상호작용 가능한 물체에는 아이콘을 띄우지 않는다. 시선 정지와 음향 변화로 유도한다.
- 엔딩 시퀀스 중 일시정지·접근성 설정·자막 설정은 계속 사용할 수 있다.

## 5. E01 — 거짓 침실

### 공간 명세

| 항목 | 값 |
| --- | --- |
| 방 크기 | 6 × 5 × 3유닛 |
| 시작 | 침대 머리맡, 시선은 천장 10도 위 |
| 이동 범위 | 침대 옆 2 × 3유닛 |
| 주요 오브젝트 | 창, 촛불, 문, 거울, 원형 먼지, 시계 |
| 조명 | 새벽의 차가운 측광 1개 + 촛불 |

```text
평면도
┌──────── 창 ────────┐
│ 촛불         거울  │
│                    │
│ [침대/시작]  ○먼지 │
│              문 >  │
└────────────────────┘
```

### 위화감 단계

| 시간/행동 | 육안 상태 | 자각 중 상태 | 지역 흔적 |
| --- | --- | --- | --- |
| 0~8초 | 완전히 자연스러움 | 미세한 숨소리만 변화 | 안도 유지 |
| 8~20초 | 시계 초침이 한 번 건너뜀 | 벽 질감이 2프레임 되감김 | 잔재 |
| 20~35초 | 촛불 그림자가 광원 반대가 아님 | 거울 속 인물이 숨죽여 작아짐 | 응시 |
| 35~60초 | 창밖 구름이 반복 | 2초 뒤 구름 위치 고스트 | 균열 |
| 60초 이후 | 손이 미세하게 떨림 | 세 흔적이 동시에 선명 | 자각 유도 |

자각을 1초 이상 유지하면 흔적이 보이지만 즉시 컷신으로 넘어가지 않는다. 플레이어가 벽,
거울, 창 중 두 곳을 직접 바라봐 흔적을 확인하면 문이 호흡하듯 한 번 움직인다. 문을 열거나
자각을 다시 사용하면 E02로 전환한다.

### 실패 방지

- 90초 동안 진행하지 않으면 세 물체의 소리가 중앙으로 모여 자연스럽게 둘러보게 한다.
- 자각 버튼을 직접 표시하지 않는다. 접근성 모드에서만 손목 주변에 기존 자각 색의 약한 링을 낸다.
- 침실 밖으로 나가거나 낙하하는 경로는 없다.

## 6. E02 — 겹친 기억

1. 화면 1~2초 암전.
2. 잔재의 복원 골드 파편, 응시의 닫혔다 뜨는 눈, 균열의 미래 고스트를 각각 0.5~0.8초
   보여준다.
3. 완전한 과거 장면이나 설명 텍스트는 사용하지 않는다.
4. 중앙에 T04의 원형 빛 배열이 나타나고, 플레이어가 앞으로 입력하면 원 안으로 이동한다.
5. 입력하지 않아도 3초 뒤 원이 천천히 다가오지만, 스킵 입력은 허용한다.
6. 총 길이는 5~8초이며 E03의 같은 침실로 하드컷하지 않고 밝기 매치로 연결한다.

---

## 7. E03·E04 — 같은 아침과 창가

### E03 변화

공간 배치는 E01과 같지만 다음 차이를 둔다.

| 요소 | 거짓 침실 | 진짜 침실 |
| --- | --- | --- |
| 시계 | 초침 누락 | 불규칙하지만 자연스러운 기계 오차 |
| 촛불 | 그림자 방향 오류 | 창빛과 일치 |
| 거울 | 지연된 반사 | 정상 반사 |
| 먼지 | 완벽한 원 | 흐트러진 자연 분포 |
| 자각 | 세 지역 흔적 노출 | 추가 정보 없음 |
| 소리 | 저역이 비어 있음 | 먼 생활 소리와 옅은 음악 |

플레이어는 자각을 사용할 수 있다. 사용해도 화면은 잠시 차분해질 뿐 숨은 표시나 “이상 없음”
문구를 내지 않는다. 확인 행동 자체를 벌주거나 실패 처리하지 않는다.

### E04 완료 조건

1. 자각 입력을 놓은 상태로 2초 유지한다.
2. 침대에서 일어나 창 방향으로 2유닛 이상 이동한다.
3. 창가에 도달하면 플레이어의 손이 프레임 아래로 내려가고 처음으로 옅은 음악이 시작된다.
4. 얼굴과 신원은 보여주지 않는다.
5. 화면이 흰색으로 날아간 뒤 제목 `Hidden Weight`와 완료 시간을 표시한다.

30초 이상 자각을 계속 홀드하면 음악의 첫 두 음이 들리고 창가 커튼이 움직여, 버튼을 놓고
이동하는 행동을 부드럽게 유도한다. 강제 해제는 하지 않는다.

| 시점 | 저장 |

- 엔딩 재생은 EH01 장치에서 별도 선택할 수 있다.

## 10. 완료 기준

- 최종 파편 없이 엔딩으로 잘못 진입할 수 없다.
- 미획득 조건은 텍스트 목록보다 공간과 기억 장치로 추론할 수 있다.
- 거짓 침실에서 자각은 플레이어가 먼저 사용하며, 시스템이 정답 버튼을 직접 띄우지 않는다.
- 진짜 침실에서 자각을 사용해도 거짓 정보나 성공 문구가 나오지 않는다.
- 마지막 완료 행동은 “자각 버튼을 놓고 창가로 이동하기”다.
- 엔딩 전체가 4~7분이며 두 침실의 차이를 플레이어가 최소 두 가지 이상 설명할 수 있다.
- 중도 종료, 재개, 재시청, 완료 후 탐험이 저장 상태를 깨뜨리지 않는다.
