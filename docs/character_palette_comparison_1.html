캐릭터 팔레트 비교

02 가독성 체크 — 균열(밝은 배경) 구간

밝은 배경에서는 그림자 보정이 필요해요

무드보드의 균열 지역도 배경이 밝은 파스텔이라, 캐릭터는 옅은 라벤더 틴트(22% 농도)만으로는 부족하고 뒤쪽에 옅은 그림자를 깔아 대비를 확보해야 해요. 무드보드 속 캐릭터도 밝은 꽃밭 위에서 은은한 그림자를 달고 있어요.

04 의상 구조 — 튜닉 + 반바지·레깅스 (망토 없음)
Draft v1에서 처음 정하신 의상 방향이에요. 지금 캐릭터 실루엣도 이 구조 그대로 반영돼 있어요 — 상의(튜닉)와 하의(반바지·레깅스)가 분리된 두 개의 도형으로 구성되고, 망토에 해당하는 파츠는 아예 없어요.
튜닉 (상의)
몸통을 감싸는 사다리꼴 실루엣 — 메트로배니아 애니메이션에 유리한 단순한 형태
반바지 + 레깅스 (하의)
튜닉 아래로 살짝 드러나는 별도 파츠. 다리 움직임 애니메이션이 튜닉에 가리지 않게 함
신발
단순한 실루엣으로 처리, 색은 의상 톤보다 한 단계 어둡게
✕
망토 — 사용 안 함
할로우 나이트와의 차별화 포인트로 의도적으로 제외. 실루엣에 망토 파츠가 없는 것을 확인할 수 있어요

✅ 재조정 결과 요약

  • 의상은 튜닉 + 반바지·레깅스 조합, 망토는 사용하지 않음 (04절)
  • 캐릭터 베이스(타입 A) 컬러는 변경 없음 — 무드보드 속 캐릭터도 거의 무채색 흰 존재로 표현됨
  • 지역 진입 시 캐릭터에 그림자 틴트를 곱하기 블렌드로 적용 — 잔재 남색 / 응시 보라 / 균열 저농도 라벤더
  • 균열(밝은 배경)에서는 틴트만으로 부족해 배경 그림자를 함께 사용 (02절)
  • 감정 이펙트 컬러(눈·손끝·발자국)는 기존 값 유지, 그림자 틴트와는 별개 레이어
