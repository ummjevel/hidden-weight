# Fracture Map and Room Concepts Design

## 1. 목표

세 번째 지역 `균열`을 한 장의 거대한 탐험 지도와 그 안에 속한 메인 룸 12개, 비밀방 3개의
연속된 사이드뷰 배경으로 제작한다. 전체 지도와 룸 이미지는 같은 건축물, 지형 고도, 진행 방향,
랜드마크를 공유해야 하며 캐릭터와 실제 게임 오브젝트는 포함하지 않는다.

## 2. 기준 자료

- 시각 기준: `docs/concept-art/04-fracture-liminal-paradise-v3.png`
- 레벨 기준: `docs/LEVEL_40_FRACTURE_DESIGN.md`
- 기존 제작 방식 기준:
  - `HiddenWeight/Assets/Art/Residue/Room01`~`Room12`, `Secret01`~`Secret03`
  - `HiddenWeight/Assets/Art/Gaze/Room01`~`Room12`, `Secret01`~`Secret03`
- 사용자 제공 이미지는 원본 시각 기준의 최신 사본으로 사용한다.

## 3. 전체 지도 구성

```text
F12 내일의 균열·지역 보스
             │
F11 아직 오지 않은 폐허 ─ FS3 선택되지 않은 문
             │
F10 초침 감시탑 ───────────┐
             │              │ 숏컷 C
F09 거울 가능성실           │
             │              │
F08 역행 승강축 ─────── F07 부유 건축군
      │ 숏컷 B               │
      └──── F03 가능성 광장 ─ F06 시차 온실 ─ FS2 멈춘 오후
                   │               │
F01 유리 정원 → F02 어긋난 산책로  F05 예지 성소
                   │               │ 숏컷 A
                   └─ F04 하층정원 ┘
                          │
                    FS1 버려진 가능성
```

전체 지도는 좌측 하단에서 시작해 중앙 허브를 반복 방문한 뒤 우측과 상층으로 상승하는
순환형 구조다. `F03 가능성 광장`에서는 `F05 예지 성소`, `F08 역행 승강축`,
`F10 초침 감시탑`, `F12 하늘 균열`의 방향을 동시에 읽을 수 있어야 한다.

## 4. 시각 정체성

- 기본 팔레트: 파스텔 민트, 빙청색, 라벤더, 옅은 살구색, 백색 대리석.
- 재질: 반투명 유리, 물에 잠긴 대리석, 희고 얇은 석재 아치, 라벤더 덩굴과 꽃.
- 조명: 밝은 확산광과 부드러운 구름광. 플레이 지형은 배경보다 한 단계 진한 명도 경계를 갖는다.
- 원본의 밝고 평온한 인상은 유지한다.
- 노골적인 살점, 피, 눈, 이빨, 괴물 실루엣은 사용하지 않는다.
- 불안감은 전체 인상의 약 5%만 차지한다.

## 5. 미세 공포 규칙

- 좌우가 거의 같지만 계단 수나 기둥 간격 하나가 어긋난 잘못된 대칭.
- 수면 반사가 실제 건축물보다 기둥 하나 많거나 다른 방향으로 이어짐.
- 꽃줄기의 일부가 자세히 볼 때 관절처럼 꺾이지만 즉시 생물로 읽히지 않음.
- 현재에는 없는 문, 다리, 계단이 희미한 미래 고스트로만 나타남.
- 멀리 있는 동일한 아치가 비정상적으로 반복되어 백룸 같은 무한감을 줌.
- 그림자와 광원 방향이 5~10도 어긋나지만 장면의 아름다움을 해치지 않음.

## 6. 전체 지도 이미지

### 포함

- F01부터 F12까지의 상대 위치와 높이.
- 중앙 허브, 하층정원, 예지 성소, 온실, 부유 건축군, 승강축, 거울 회랑,
  초침 감시탑, 미래 폐허, 하늘 균열.
- 계단, 아치형 다리, 승강축, 끊어진 산책로, 이동 가능한 유리 발판이 만드는 진행 흐름.
- 비밀방으로 이어지는 막힌 아치나 수면 아래 실루엣.

### 제외

- 플레이어 캐릭터와 인간형 실루엣.
- 적, 보스, 아이템, UI, 텍스트, 숫자, 지도 라벨, 워터마크.
- 원본의 보라색 와이어프레임 블록아웃.
- 충돌 판정이 불분명한 과도한 장식과 화면을 가리는 전경.

전체 지도는 1672×941의 넓은 2D 사이드뷰 콘셉트 이미지로 저장한다.

| ID | 이름 | 전체 지도에서의 위치 | 구도와 랜드마크 |
| --- | --- | --- | --- |
| F01 | 유리 정원 | 좌측 하단 입구 | 낮은 수면, 온전한 아치, 첫 하늘 균열 실루엣 |
| F02 | 어긋난 산책로 | F01 우측 | 상부 붕괴 산책로와 안전한 하부 우회로 |
| F03 | 가능성 광장 | 중앙 하단 허브 | 여러 고도 출구, 중앙 문틀, 멀리 보이는 감시탑 |
| F04 | 흔들리는 하층정원 | F03 아래 | 수면 가까운 화단과 반복 이동하는 낮은 발판 |
| F05 | 예지 성소 | F04 우측 상단 | 세로 광선, 예지 제단, 미래 위치의 희미한 문 |

| F07 | 부유 건축군 | 우측 중층 | 교차하는 수평·수직 건축 조각과 넓은 안전 섬 |
| F08 | 역행 승강축 | 중앙 상층 | 깊은 수직 축, 층별 안전 포켓, 역방향 승강기 |
| F09 | 거울 가능성실 | F08 상단 | 좌우 대칭 회랑과 서로 다르게 반사되는 수면 |
| F10 | 초침 감시탑 | 상층 중앙 | 원형 시계바늘 구조와 하늘을 향한 탑 |
| F11 | 아직 오지 않은 폐허 | 최상층 진입부 | 현재에는 기초만 있고 미래 윤곽만 완성된 폐허 |
| F12 | 내일의 균열 | 최상단 종착점 | 세 갈래 하늘 균열과 붕괴 가능한 넓은 전장 |

| FS2 | 멈춘 오후 | F06 바깥 온실 | 멈춘 빛과 꽃가루, 역방향 발판이 닿는 작은 정원 |
| FS3 | 선택되지 않은 문 | F11 측면 | 빈 벽과 세 번 반복되는 미래 문 실루엣 |

각 룸 이미지는 1672×941이며, 캐릭터나 게임 오브젝트 없이 배경과 이동 가능 공간의 관계만
보여준다. 인접 룸은 출입구의 높이, 다리 방향, 보이는 랜드마크가 일치해야 한다.

분리는 전체 지도와 15개 룸 콘셉트가 검수된 뒤 별도 단계로 진행한다.

## 9. 생성 순서

1. 원본을 참조해 캐릭터와 와이어프레임을 제거한 전체 지도 제작.
2. F01~F03의 입구·허브를 제작해 전체 지도의 이동 축 고정.
3. F04~F06의 하층정원·성소·온실 제작.
4. F07~F09의 부유 건축·승강축·거울 회랑 제작.
5. F10~F12의 감시탑·미래 폐허·보스 종착점 제작.
6. FS1~FS3의 비밀방 제작.
7. 전체 지도와 15개 룸의 팔레트, 랜드마크, 출구 높이, 진행 방향 검수.

## 10. 완료 기준

- 캐릭터와 와이어프레임이 제거된 전체 지도 1장.
- 메인 룸 12장과 비밀방 3장.
- 모든 이미지가 1672×941.
- 모든 이미지에 캐릭터, 적, 아이템, UI, 텍스트, 워터마크가 없음.
- F01→F12의 고도 상승과 중앙 허브 순환이 전체 지도와 룸 이미지에서 동일함.
- 원본 팔레트와 밝은 낙원 인상을 유지하고 미세 공포가 약 5%만 존재함.
- 프롬프트 기록과 전체 컨택트시트가 저장됨.
