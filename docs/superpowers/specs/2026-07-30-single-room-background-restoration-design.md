# 방별 단일 배경 복원 설계

## 목표

잔재·응시·균열의 15개 방을 각 방 전용 완성 원본 이미지 한 장으로 표시한다. 분리된 패럴랙스 레이어와 캐릭터보다 앞에 표시되는 전경을 제거하고, 1920×1080 플레이 화면에서 배경 선명도와 캐릭터 가독성을 회복한다.

## 기준 소스

- 잔재: `docs/concept-art/generated/residue-rooms-v2/`의 메인룸 12장과 비밀방 3장
- 응시: `docs/concept-art/generated/gaze-rooms-v1/`의 메인룸 12장과 비밀방 3장
- 균열: `HiddenWeight/Assets/Art/Fracture/Rooms/FractureRoom*.png` 및 `FractureSecret*.png`

현재 저장소에서 확인되는 방별 완성 원본은 모두 `1672×941`이다. 저장소와 Git 기록에 더 큰 원본이 없으므로 우선 이 파일을 무손실 임포트해 사용한다. 실제 1080p 캡처에서 흐림이 남는 방만 별도 고해상도 보정 대상으로 분류한다.

## 에셋 구조

잔재와 응시의 완성 원본을 런타임 에셋 아래에 복사한다.

```text
HiddenWeight/Assets/Art/Residue/Rooms/
  ResidueRoom01.png ... ResidueRoom12.png
  ResidueSecret01.png ... ResidueSecret03.png

HiddenWeight/Assets/Art/Gaze/Rooms/
  GazeRoom01.png ... GazeRoom12.png
  GazeSecret01.png ... GazeSecret03.png
```

균열의 기존 `Assets/Art/Fracture/Rooms/` 구조를 기준 구현으로 삼는다.

방별 완성 원본은 Sprite/Single, mipmap 비활성, Clamp, Bilinear, 최대 크기 2048로 임포트한다. 잔재·응시는 무압축, 균열은 현재의 Standalone CompressedHQ 설정을 유지한다.

## 씬 구성

각 `Room` 아래에는 `RoomBackground` 오브젝트 하나만 둔다.

- 정렬 순서: `-30`
- 방 중심에 배치
- `RoomVisualCuller`를 부착해 현재 방 밖의 배경을 렌더링하지 않는다.
- `BG_Far`, `BG_Mid`, `FG_Overlay`, `Far`, `Mid`, `Foreground` 오브젝트는 생성하지 않는다.
- `MotionFront`는 모든 지역에서 생성하지 않는다.
- `MotionBack`도 단일 완성 원본과 중복되므로 생성하지 않는다.

캐릭터보다 앞에 그려지는 지역 장식은 이 작업 범위에서 허용하지 않는다. 게임플레이 오브젝트와 이펙트는 기존 정렬값을 유지한다.

## 스케일과 카메라

기본 가로형 방은 원본 비율을 유지한 채 방 너비에 맞춘다. 세로형 방은 방 전체 높이를 덮도록 이미지를 과도하게 확대하지 않는다.

- 카메라 가시 영역을 기준으로 필요한 최소 크기만 확보한다.
- 남는 세로 공간은 배경색 또는 상하 확장 가능한 원경 영역으로 처리한다.
- 원본을 비균일하게 늘리지 않는다.
- Room04와 Room08은 별도 세로형 배치 규칙을 사용한다.
- Room08 최상단 출구에서는 플레이어 머리가 카메라 상단에 잘리지 않도록 방 경계에 최소 1.5 유닛의 상단 여유를 추가한다.

## 지형 정합성

단일 배경 적용 후 각 방의 충돌 지형과 그림 속 바닥·발판을 비교한다.

- 실제 이동 가능한 표면과 그림의 표면 높이 차이가 0.5 유닛을 넘는 경우 배치 코드를 수정한다.
- 큰 단색 `GroundTile` 면이 카메라에 노출되는 곳은 지형 아트로 덮거나 Tilemap 렌더러를 숨긴다.
- 충돌 판정은 유지하며 시각 오브젝트만 숨기는 것을 우선한다.
- 이동 경로를 바꾸는 좌표 수정은 기존 자동 주파 테스트가 통과하는 범위에서만 허용한다.

## 검증

자동 검증:

- 45개 방 모두 `RoomBackground`를 정확히 하나 가진다.
- 레거시 배경 레이어와 `MotionFront`가 씬에 존재하지 않는다.
- 방별 배경 스프라이트가 올바른 원본 파일을 참조한다.
- 기존 잔재·응시·균열 주파 및 아트 배선 테스트가 통과한다.

시각 검증:

- 각 방 전체 구도와 플레이어 근접 화면을 1920×1080 기준으로 캡처한다.
- 캐릭터 위에 전경이 겹치지 않는다.
- Room04·Room08에서 과도한 확대, 검은 띠, 캐릭터 상단 잘림이 없다.
- 단색 임시 타일이 게임플레이 화면의 넓은 면적으로 노출되지 않는다.
- 배경과 캐릭터·발판의 명도 대비가 이동과 전투에 충분하다.

## 제외 범위

- 신규 방 콘셉트 제작
- 적·보스·UI 아트 교체
- 전체 맵 동선 재설계
- 저장소에 존재하지 않는 고해상도 원본을 추정해 일괄 생성하는 작업

고해상도 보정은 단일 배경 복원 후 실제 캡처에서 흐림이 확인된 방만 별도 작업으로 진행한다.
