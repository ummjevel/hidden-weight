## 0. 지역 제작 목표

응시는 숨죽이기를 강한 은신 기술로 소개한 뒤, 계속 숨는 것만으로는 앞으로 갈 수 없게
만드는 지역이다. 맵은 낮은 틈과 시선 엄폐를 초반에 반복하고, 후반으로 갈수록 플레이어가
몸을 다시 드러내고 자각으로 진짜 정보를 판별하도록 공간을 연다.

```text
G01→G02→G03→G04→G05→G06→G07→G08→G09→G10→G11→G12
              └GS1       └GS2                         └GS3
```

### 카메라·시선 공통 규칙

- 시선 원뿔의 끝은 현재 카메라 안에 보여야 한다.
- 회전 시선 구간은 구간별 고정 앵커로 원인과 안전지대를 함께 보여준다.
- 시선 포착은 0.5초 경보 뒤 체력 1 피해와 최근 안전 앵커 복귀로 처리한다.
- 복귀 뒤 0.8초 동안 시선과 적에게 감지되지 않는다.
- 숨죽이기 중 이동속도 65%, 공격 불가, 시선 완전 미감지를 기준으로 한다.
- 안전 포켓은 최소 폭 3유닛이며 회전 시선 한 주기를 관찰할 수 있다.

## 2. 방별 명세

### 2.1 G01 — 눈꺼풀 경계

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 26×14 / D0 / 1~2분 |
| 입구 / 출구 | W `(0,3)` / E `(26,3)` |
| 체크포인트 | `(5,3)` |
| 카메라 | 한 화면 고정→끝에서 약한 추적 |

```text
        닫힌 거대 눈(Far)       감시탑(Far)
K P _________      ____        __________ >
#############_____/    \______############
```

- 연속 바닥 `x=0~26, y=2`, `x=10~14`에 높이 1.5유닛 완만한 곡선을 둔다.
- 첫 시선 빛은 `(22,8)` 배경 벽만 4초 주기로 훑고 플레이어 판정은 없다.
- 입력 안내, 적, 낙하를 두지 않는다. `gaze_g04`로 이어질 철창 실루엣을 Mid에 먼저 보인다.
- 첫 방문 뒤 체크포인트는 유지하며 재방문 시 도입 연출을 반복하지 않는다.
- 검증: 정지 상태에서도 출구, 거대 눈, 감시탑 세 방향이 서로 겹치지 않는다.

### 2.2 G02 — 고정된 시선교

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 30×16 / D1→D2 / 2~3분 |
| 입구 / 출구 | W `(0,3)` / E `(30,4)` |
| 적 | 눈먼 순례자 `(18,4)`, 체력 2 |
| 복귀 | `(7,3)`, `(22,3)` |
| 카메라 | 2개 고정 앵커 |

```text
       👁→→     기둥       ←←👁
P ____   # ____  #  ____ E ______ >
######\__#~~~~#__#_/################
       하부 무피해 길 R
```

- 고정 시선 A `(8,10)`은 `x=6~12`, B `(25,10)`는 `x=21~27`을 비춘다.
- 기둥 `(10,2~9)`, `(21,2~9)` 뒤에서 시선이 완전히 차단된다.
- 첫 포착은 피해 없이 `(7,3)`으로, 이후 포착은 체력 1 피해로 처리한다.
- 상부 길 실패는 `y=1` 하부 우회로로 이어져 15초 안에 합류한다.
- 순례자는 두 시선 사이 안전 평지에 있어 시선과 첫 전투가 겹치지 않는다.
- 완료: 플레이어가 엄폐, 하부 우회, 피격 중 하나로 시선 규칙을 이해한다.

### 2.3 G03 — 관객 광장

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 32×20 / D1 / 2~3분 |
| 입구 | W `(0,4)` |
| 첫 출구 | SE G04 `(29,2)` |
| 잠긴 연결 | NW A `(5,13)`, U B `(25,11)` |
| 적 | 순례자 `(18,4)`, 우회 가능 |
| 카메라 | 중앙 고정 + 출구 추적 |

```text
 L(A)                         L(B 승강기)
  ####                         ####
      \      관객 광장       /
P _____\_______ E __________/____
###########################\___ > G04
```

- 중앙 안전 광장은 `x=8~24, y=2~5`; G04 길은 가장 낮고 밝게 만든다.
- A 사슬막 장치 `(6,12)`, B 승강기 정지점 `(25,6)`, 지도 지점 `(15,5)`.
- G05 완료 후 A가 열리고, G08 완료 후 B가 내려온다.
- 재방문 시 적 순찰은 중앙 아래 5유닛에 한정해 숏컷 이동을 방해하지 않는다.
- 완료: 첫 방문 플레이어의 90%가 30초 안에 G04를 찾는다.

### 2.4 G04 — 하층 새장원

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 26×24 / D2 / 3분 |
| 입구 / 출구 | NW `(2,22)` / SE G05 `(24,2)` |
| 비밀 | GS1 `(7,6)` |
| 적 | 순례자 `(15,14)`, `(19,4)` |
| 복귀 | `(6,17)`, `(13,10)`, `(20,3)` |
| 카메라 | 세로 구간 앵커 3개 |

```text
P __ 철창 __
####       \=== E
   #  R       \____
   #      === E    \
   #  S?            \____ >
############################
```

- `y=18~22` 관찰대, `y=8~17` 지그재그 하강, `y=2~6` 하층 안전 바닥으로 나눈다.
- 발판 추락은 아래 구간으로 이어지며 피해가 없다. 다시 오르는 굴뚝 폭은 4유닛이다.
- GS1은 `(6~9,6)`의 철창 그림자 한 칸 누락, 관객 방향, 끊긴 소리로 암시한다.
- 기억 `gaze_g04`는 `(21,4)`, 출구와 반대쪽 짧은 선택 발판에 둔다.
- 철창 속 존재들은 가까이 가면 반대 방향을 본다. 전투보다 환경 서사를 우선한다.

### 2.5 GS1 — 무대 뒤편

- 파편 `(15,4)` 획득 뒤 복귀용 철창 사다리가 열린다.

### 2.6 G05 — 숨죽임 성소

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 28×16 / D0→D2 / 3~4분 |
| 입구 / 출구 | W `(0,3)` / E G06 `(28,3)` |
| 숏컷 | NW A `(22,11)` → G03 |
| 체크포인트 / 능력 | `(6,3)` / 숨죽이기 `(10,4)` |
| 카메라 | 한 화면 추적 |

```text
                     L(A)
                     ###
P K __ [스킬] __ 낮은 틈 __ 👁 __ 표적 E __ >
###########____#############################
```

1. 능력 획득 뒤 높이 0.9유닛 틈 `x=13~16`을 축소 상태로 통과한다.
2. 고정 시선 `(19,9)` 아래 4유닛을 숨죽여 이동한다.
3. 무해 훈련 표적 `(23,3)` 앞에서 숨죽이면 공격 불가 아이콘을 확인한다.
4. 사슬막 `(22,10)`을 안에서 열어 G03 A와 연결하고 `gaze_skill`을 기록한다.
- 적, 피해, 시간제한 없음. 세 단계 사이 폭 4유닛 안전 바닥을 둔다.

### 2.7 G06 — 속삭임 통로

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 34×16 / D2 / 3~4분 |
| 입구 / 출구 | W `(0,3)` / E `(34,4)` |
| 비밀 | GS2 `(25,2)` 역방향 낮은 틈 |
| 적 | 밀고하는 입 `(12,4)`, `(26,5)`, 체력 3 |
| 복귀 | `(8,3)`, `(22,3)` |
| 카메라 | 가로 추적, 세 구간 Clamp |

```text
    낮은 틈       열린 구간          역방향 S
P __[____]__ E 👁 ____#____ E ____<___S
######R################R############### >
```

- 낮은 천장 `x=6~10`, `18~21`, 열린 구간 `11~17`, `22~29`를 번갈아 둔다.
- 입은 0.9초 비명 예고 뒤 연결 시선을 3초 활성화한다. 숨죽이면 표적을 잃고 비명을 취소한다.
- 첫 입은 처치·은신 통과 모두 가능하다. 두 번째는 GS2 반대 방향을 지킨다.
- 계속 숨죽이면 느려져 열린 구간 이동 시간이 늘어나므로 해제 타이밍이 유리하다.

| 입구 / 출구 | W `(0,4)` / E `(32,5)` |
| 비밀 | GS3 `(22,12)` |
| 능력 / 기억 | 자각 `(16,5)` / `gaze_g11` `(27,5)` |
| 카메라 | 느린 가로 추적, 해금 시 고정 |

```text
        지연 거울      [거대 눈/자각]       S(GS3)
P ______ | | _____________ A ____________ M ___ >
################################################
```

- 전투·낙하 없음. 거울 `(7,5)`, `(11,5)`, `(15,5)`은 점점 짧은 지연 반사를 보인다.
- 거대 눈 `(16,10)` 앞에서 4초 이하 해금 연출 후 `HasAwareness`를 저장한다.
- 자각 중 보이는 바닥 표식 `(18~22,3)`을 따라 한 화면 안전 퍼즐을 통과한다.
- 같은 상태에서 GS3 거울문 `(22,12)`이 보이되 주 출구와 반대 위쪽에 둔다.
- 해금 뒤 이 방에 다시 오면 연출 없이 자각 표식과 GS3가 즉시 반응한다.

### 2.14 GS3 — 안쪽 눈

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 20×14 / D0 / 1~2분 |
| 입구 / 복귀 | W `(0,4)` / 동일 문 |
| 조건 | 자각 보유 |
| 보상 | 응시 선택 서사 파편, 큰 재화 |

```text
P ______ 역방향 그림자 ______ [안쪽 눈] M
#########################################
```

- 자각을 놓으면 공간은 남지만 벽의 얼굴과 그림자가 흐려진다. 진행을 막지는 않는다.
- 전투·낙하·시간제한 없이 60~90초 서사 공간으로 유지한다.
- 파편 획득 뒤 거울문은 영구 가시화되어 재방문에 자각을 강제하지 않는다.

### 2.15 G12 — 만인의 극장

| 항목 | 값 |
| --- | --- |
| 크기 / 난이도 / 시간 | 34×22 / D5 / 6~8분 |
| 입구 / 다음 지역 | W `(0,5)` / E `(34,6)` → F01 |
| 보스 | 만인의 시선, 체력 30 |
| 보상 | `gaze_final`, `gaze_core`, 균열문 |
| 복귀 | G10 체크포인트, 3분 이내 |
| 카메라 | 전체 전장 고정, 단계 줌 5% 이하 |

```text
관객 👁 👁 👁 👁 👁 관객
   [좌 엄폐]   X무대   [우 엄폐]
P _________=== 중앙 ===____________ >
######################################
```

- 전장은 좌우 엄폐막 `x=7,27`, 중앙 무대 `x=12~22, y=3`, 상부 관객석 `y=12~19`로 읽힌다.
- 1단계 고정·회전 시선, 2단계 가짜 판결, 3단계 지연 분신, 4단계 마주 보기 순서다.
- 자각 중 실제 공격 주체의 그림자만 바닥과 일치하고 0.25초 안에 구분된다.
- 숨죽이기는 시선 회피, 자각은 공격 기회 판별이다. 둘을 동시에 요구하지 않는다.
- 승리 후 모든 관객이 서로를 바라보고 위험을 비활성화한다. 두 파편을 순차 기록한 뒤 F01 문을 연다.
- 보스 입장 연출은 재도전 시 1초 이하, G10→G12 이동은 열린 C 기준 3분 이하.

## 4. 전체 난이도·카메라 검증

```text
D0 G01 → D1~2 G02 → D1 G03 → D2 G04 ─ D2 GS1
→ D0~2 G05 → D2 G06 ─ D4 GS2 → D3 G07 → D2 G08
→ D4 G09 → D4 G10 → D0~2 G11 ─ D0 GS3 → D5 G12
```

- 고정·회전 시선의 위험 끝과 다음 안전 포켓이 같은 카메라 구도에 보인다.
- 숨죽이기 획득 후 3분 안에 축소, 은신, 공격 불가를 모두 경험한다.
- G07 시선 주기는 관찰로 무피해 통과할 수 있고 무작위 위상을 사용하지 않는다.
- G09와 두 보스는 숨죽이기 유지 하나만으로 완료할 수 없다.
- 자각 해금 직후 필수 표식 1개와 선택 GS3를 같은 방에서 발견한다.
- 일반 방 실패 복귀 20초, 중간 보스 20초, 지역 보스 3분 상한을 지킨다.
- 주 동선 30~40분, 선택 포함 40~50분을 목표로 한다.
