# 균열(3맵) 디자인 개선 — 설계

> 기준일: 2026-08-02
> 대상 지역: 균열(Fracture) — 메인방 F01~F12, 비밀방 FS1~FS3
> 상위 문서: `LEVEL_40_FRACTURE_DESIGN.md`, `LEVEL_41_FRACTURE_ROOMS.md`
> 코드 기준: `HiddenWeight/Assets/Scripts/World/CameraLockedRoomBackground.cs`,
> `Scripts/Enemies/`, `Scripts/Editor/Fracture*`

---

## 0. 문제

균열을 처음 플레이하는 사람이 겪는 것 세 가지다.

1. **공간이 박스와 선으로 보인다.** 밟는 지형이 납작한 사각형이고 그 위에 형광 테두리가 둘러져
   디버그 화면처럼 읽힌다.
2. **몬스터 움직임이 부자연스럽다.** 미끄러지고, 방향이 툭 끊기고, 몸과 진행 방향이 어긋난다.
3. **어디로 가서 뭘 해야 할지 알 수 없다.** 막힌 이유는 알려주지만 나아갈 곳은 알려주지 않는다.

## 1. 원인

### 1.1 지형 — 아트가 실제로 박스다

`Fracture_TerrainTiles_v1.png`의 24칸은 전부 같은 납작한 사각형에 테두리만 두른 그림이다.
`docs/concept-art/generated/fracture-gameplay-art/build_fracture_gameplay_art.py`의
`terrain_tiles()`가 PIL `marble_block()`(다각형 fill + outline)으로 그린 플레이스홀더다.

이후 커밋 `5e33833`의 이미지 생성 패스가 적·보스·발판 시트는 일러스트로 교체했으나
**지형과 프롭 시트는 교체하지 않았다.** 잔재는 `Residue_TerrainTiles_v2`에서 일러스트
소스로 교체돼 끝단·기둥·아치·경사 실루엣을 갖는다 — 두 지역의 격차가 여기서 생긴다.

문제는 세 겹이다.

| 층 | 현재 |
| --- | --- |
| 아트 | 24칸이 전부 같은 납작한 사각형 |
| 선택 | 런타임이 그중 `FractureTerrain_r1_c3` **한 칸만** 뽑아 모든 바닥·벽에 늘여 쓴다 |
| 덧그림 | 그 위에 흰색·청록 테두리 밴드를 네 면 전부에 두른다 |
| 미사용 | 일러스트로 완성된 `Fracture_Platforms_v1`(고딕 크리스탈 발판 12종)이 씬에서 안 쓰인다 |

테두리 밴드는 "안 보이는데 부딪히는 벽"을 막으려고 넣은 응급처치다. 걷어내려면 아트가
그 역할을 대신해야 한다.

### 1.2 몬스터 — `EnemyPatrol`이 아니라 지역 전용 이동이다

균열 적 4종은 예지 공정성("고스트가 보여준 위치 = 실제 2초 뒤 위치", 설계 7.2) 때문에
궤도가 시간의 순수 함수여야 하고, 그래서 `EnemyPatrol`을 끄고 자체 이동을 쓴다
(`FeintPatrol`, `PrecursorBehavior`, `CollectorBehavior`, `SplitSelfBehavior`).

| 증상 | 원인 |
| --- | --- |
| 미끄러짐 | 반환점에서 속도가 0인데도 `PlayClip("Walk")`를 무조건 호출한다 |
| 발이 지면을 안 짚음 | `SpriteAnimator`의 클립 fps가 고정이라 이동 속도와 무관하다 |
| 방향 전환이 툭 끊김 | `FaceTowards`가 `localScale.x`를 한 프레임에 반전한다 |
| 몸과 진행이 어긋남 | 페인트가 스케일을 반전시킨다 — 의도된 연출이나 버그로 읽힌다 |
| 막히면 튐 | `drift` 보정이 위치 오차를 쌓았다가 최대 4×속도로 되돌린다 |

### 1.3 길 안내 — 진행 방향을 알려주는 장치가 없다

있는 것은 `BlockedHint`(막힌 이유 문구)뿐이다. 방 문은 로드되지 않은 다른 씬이라 눈으로는
길인지 벽인지 구분되지 않고, 설계 4.1·4.2가 규정한 F01·F02의 무텍스트 학습 연출
("닿기 전에 스스로 무너지는 발판", "상부 붕괴 → 무피해 하부 복귀")은 구현돼 있지 않다.

## 2. 설계

### 2.1 Part 1 — 지형 타일셋 v2와 역할 기반 선택기

#### 아트: `Fracture_TerrainTiles_v2.png` (6×4)

이미지 생성 없이 만든다. 균열의 4K 룸 배경 15장(`Art/Fracture/Rooms4K/`)은 이미
일러스트로 완성돼 있고 대리석 바닥, 난간, 아치, 기둥, 유리 지붕, 등나무를 포함한다.
여기서 영역을 잘라 타일로 조립하면 팔레트와 화풍이 자동으로 일치한다.

24칸의 역할은 런타임 선택기가 요구하는 것과 1:1로 맞춘다.

| 행 | 칸 | 역할 |
| --- | --- | --- |
| 1 | 1~6 | 바닥 윗면: 좌 끝단 / 중간 반복 4종 / 우 끝단 |
| 2 | 1~6 | 세로 벽면: 좌향 / 우향 / 좁은 기둥 / 넓은 기둥 / 상단 모서리 좌·우 |
| 3 | 1~6 | 천장·아랫면: 좌 / 중 / 우 + 부유 발판 밑면(크리스탈) 3종 |
| 4 | 1~6 | 특수: 아치 / 경사 좌·우 / 붕괴 직전 균열 / 부유 끝단 2종 |

제작 규칙:

- **네 면을 모두 그린다.** 테두리 밴드를 제거하는 전제 조건이다. 윗면뿐 아니라 좌·우 측면과
  아랫면에도 실루엣과 명도차가 있어야 "안 보이는데 부딪히는 벽"이 돌아오지 않는다.
- 설계 2.1을 따라 **수직선을 미세하게 기울이고 그림자 방향을 5~10도 어긋나게** 둔다.
- 중간 반복 4종은 이어 붙였을 때 이음매가 보이지 않아야 한다.
- 붕괴 예정 타일은 평상시 금이 없거나 매우 약해야 한다(설계 2.1) — 외형만으로 구분되면
  예지의 존재 이유가 사라진다.

제작 스크립트는 `docs/concept-art/generated/fracture-terrain-v2/build_fracture_terrain_v2.py`에
두고, 잘라 온 원본 좌표를 스크립트 안에 기록해 재현 가능하게 한다. 나중에 일러스트 소스가
생기면 이 파일 하나만 교체하면 되도록 슬라이서와 이름 규칙은 그대로 둔다.

#### 런타임: `TraversalArtPalette` → 역할별 세트

`SurfaceFor(sceneName)`가 스프라이트 한 장을 돌려주던 것을 역할별 세트로 바꾼다.

```
TerrainTileSet {
    Sprite topLeft, topRight;
    Sprite[] topMid;              // 4종, 좌표 해시로 결정적 선택
    Sprite wallLeft, wallRight, wallCapLeft, wallCapRight;
    Sprite ceilingLeft, ceilingMid, ceilingRight;
    Sprite platformLeft, platformMid, platformRight;   // Fracture_Platforms_v1 3-slice
}
```

`CameraLockedRoomBackground`의 세 지점을 고친다.

| 함수 | 현재 | 변경 |
| --- | --- | --- |
| `AddTraversalSurface` | 구간 전체에 한 장을 8유닛 모듈로 반복 | 첫 칸 = 좌 끝단, 마지막 칸 = 우 끝단, 사이 = 중간 4종을 좌표 해시로 선택 |
| `AddTilemapWallFace` | 한 장을 세로로 늘임 | 벽면 타일을 세로로 반복, 최상단에 모서리 |
| `BuildPlatformSurfaces` | 한 장 + 네 면 테두리 밴드 | `Fracture_Platforms_v1` 3-slice로 폭에 맞춰 조립 |

- `AddPlatformEdge`와 `TraversalWallEdge`(테두리 밴드)를 **제거**한다.
- 배경 알파는 0.58에서 0.75 근처로 올린다. 지형이 실제 아트가 되면 배경을 눌러 둘 이유가
  줄어든다. 최종 값은 화면을 보고 정한다.
- 좌표 해시는 결정적이어야 한다. 방을 다시 로드할 때마다 타일 무늬가 바뀌면 플레이어가
  같은 방을 다른 장소로 오인한다.

**결정적 제약: 아트를 스케일로 늘리지 않는다.** 발판 아트는 루트가 아니라 스케일 1인
자식에 준다 — 루트 `localScale`을 만지면 `BoxCollider2D`가 같이 줄어 3×0.5 판정이
0.56×0.05 슬리버가 된다(잔재·응시에서 실제로 겪은 함정).

#### 회귀 방지

`FractureArtWiringTests`에 추가한다.

- 모든 Ground·Wall 콜라이더가 네 면에 렌더러를 갖는다 — 밴드 제거로 인한 퇴행을 잡는다.
- 발판 콜라이더가 스케일로 줄어 있지 않다 — 기존 검사를 유지한다.
- 지형 스프라이트가 `FractureTerrain_r1_c3` 하나로만 이루어져 있지 않다 — 선택기가 실제로
  여러 타일을 쓰는지 확인한다.

### 2.2 Part 2 — 몬스터 움직임

원인별로 대응한다. 궤도 자체는 건드리지 않는다 — 예지 공정성이 여기 걸려 있다.

| 수정 | 위치 | 내용 |
| --- | --- | --- |
| 정지·보행 분기 | `FeintPatrol` 외 3종 | 실제 \|vx\|가 임계값 이하면 `Idle`, 넘으면 `Walk` |
| 애니 속도 연동 | `SpriteAnimator` | `PlaybackSpeed` 프로퍼티 추가, 보행 클립만 \|vx\|/기준속도를 곱한다 |
| 회전 모션 | `EnemyBehavior.FaceTowards` | 0.12초에 걸쳐 x스케일을 1 → 0 → -1로 보간. 한 곳만 고치면 전 개체에 적용된다 |
| 페인트 표현 | `FeintPatrol` | 스케일 반전 대신 짧은 정지와 기울기로. 궤도는 그대로라 예지는 여전히 정확하다 |
| 막힘 복구 | `FeintPatrol` | `drift`에 상한을 두고, 0.5초 이상 막히면 궤도 원점을 현재 위치로 재기준 |

`FaceTowards`는 세 지역이 공유하므로 잔재·응시 적의 회전도 함께 부드러워진다. 이는 의도된
부수 효과이며, 회귀 검증 대상에 포함한다.

### 2.3 Part 3 — 길 안내

원칙 2("세계가 먼저, UI가 보조한다")를 따라 HUD 화살표가 아니라 월드 연출로 만든다.
범위는 셋으로 제한한다.

1. **문이 문처럼 보이게.** `RoomDoor`에 `Fracture_DoorsShortcuts_v1` 아트와 은은한 발광을
   붙인다. 지금은 콜라이더에 문구만 있어 처음 보는 사람은 벽인지 길인지 모른다.
2. **방 진입 시 진행 방향.** 방에 들어오면 다음 문 쪽으로 1.2초간 미세한 빛 흐름을 한 번만
   보여준다. 반복하지 않는다 — 반복하면 안내가 아니라 잔소리가 된다.
3. **F01·F02 학습 연출.** 설계 4.1의 "방 끝에서 닿기 전에 스스로 무너지는 발판"과 4.2의
   "상부 붕괴 → 무피해로 하부 통로 복귀"를 구현한다. 이것이 균열의 무텍스트 튜토리얼이다.

랜드마크 연속성(하늘 균열이 F01~F12 배경에 계속 보이는 것, 설계 2.3)은 배경 15장 재작업이
필요해 이번 범위에서 제외한다.

## 3. 구현 순서

**지형 → 몬스터 → 길 안내.** 지형이 화면의 대부분을 차지하고, 나머지 둘의 개선 여부는
지형이 읽힌 뒤라야 판단할 수 있다. 세 축은 서로 독립적이라 계획은 축별로 나눈다.

## 3.1 2차 리뷰 반영 (2026-08-02)

1차 구현 뒤 받은 리뷰(P0/P1)를 다음과 같이 반영했다.

| 항목 | 구현 |
| --- | --- |
| 예지가 화면을 덮음 | `ForesightSkill`을 전면 교체. 실제로 그려지는 렌더러를 찾아 그 크기로 만들고(루트 스케일·플레이스홀더 문제 동시 해결), 흰 외곽 실루엣만 남기며(`SpriteOutline`에 `_FillAlpha` 추가), 7유닛을 넘는 그림은 대상에서 제외, 가까운 3개만 강조, 발동 시 연결선 0.12초, 사라질 발판은 현재 자리에 두 번 끊어진 외곽 표시 |
| 지도가 균열인데 R01 표기 | `PauseSectionPanel`의 하드코딩 제거. 지역별 실제 방 이름표(잔재·응시·균열 15개씩)를 넣고, 세로 목록을 주 동선 가로축 + 비밀방 가지 + 숏컷 줄의 노드 그래프로 교체 |
| 탭과 콘텐츠 겹침 | 섹션 패널이 열리면 일시정지 메뉴의 제목·버튼·탭을 감춘다(`VisibilityChanged`) |
| 지형 채도·명도 | 생성기에 `grade()` 추가. 상단 밝은 대리석 → 측면 라벤더 → 하단 청록 유리를 부드럽게 잇고 채도를 0.8로 억제 |
| HUD 화풍 | 체력을 결정핵 5개로 압축(핵마다 부분 채움), 검은 패널을 옅은 그림자로, 스킬명은 2.4초만 표시, 쿨타임을 아이콘을 덮는 부채꼴에서 끊어진 이중 고리로 |
| 캐릭터 위계 | `PlayerSilhouette` — 발밑 접촉 그림자(높이에 따라 작아지고 옅어짐)와 청회색 외곽 1단 |
| 밝기 곡선 | `ApplyFractureCurve` — F01 밝음 / F02~F04 어긋남 / F05 청백 집중 / F06~F10 시간차 / F11 과도한 흼 / F12 균열광만 |
| 진행 방향 | `RoomEntryCue` — 방에 처음 들어설 때 출구 쪽으로 1.2초 빛 흐름 한 번 |
| F01 학습 | `OmenPlatform` — 다가가면 스스로 갈라져 무너지고 되살아나는 발판. 정적인 "이미 부서진 조각" 장식을 대체 |
| F02 학습 | 첫 붕괴 발판만 무너짐 지연 1.1초, 하부에서 주 동선으로 합류하는 턱에 유도 빛 |

**꽃 장식은 끝단에 남기지 못했다.** 그림의 맨 위가 곧 밟는 면이라, 끝단에만 꽃을 남기면
그 타일의 대리석이 옆 타일보다 내려가 이음매에 턱이 생긴다. 특수 행에만 남겼다.

## 4. 완료 기준

- 균열의 어떤 방에서도 형광 테두리 사각형이 보이지 않는다.
- 밟을 수 있는 지형과 배경 장식이 테두리 없이도 구분된다.
- 지형에 끝단·모서리·기둥이 존재해 같은 그림이 반복되지 않는다.
- 독립 발판이 고딕 크리스탈 아트로 그려지고, 콜라이더 크기는 변하지 않는다.
- 적이 멈출 때 걷는 애니메이션을 재생하지 않는다.
- 적의 방향 전환에 중간 프레임이 있다.
- 예지 고스트 위치와 실제 2초 뒤 위치가 여전히 일치한다.
- 방에 들어온 사람이 다음에 갈 문을 찾을 수 있다.
- F01·F02를 지나면 "밝음이 안전을 보장하지 않는다"를 텍스트 없이 이해한다.
- `FractureArtWiringTests`가 전부 통과하고, 기존 통과 테스트가 깨지지 않는다.
