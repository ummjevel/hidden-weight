## 0. 목적

이 문서는 맵에 들어가는 몬스터, 아이템, 수집품, 보상, 상호작용 요소의 공통 규칙을
정의한다. 목표는 새로운 콘텐츠를 추가할 때 기존 방이나 플레이 흐름을 직접 뜯어고치지 않고,
방의 정해진 슬롯에 콘텐츠를 연결할 수 있게 하는 것이다.

```text
지역
└─ 방
   ├─ 지형과 출입구
   ├─ 조우 슬롯
   ├─ 보상 슬롯
   ├─ 상호작용 슬롯
   └─ 지속 상태
```

---

## 1. 콘텐츠 설계 원칙

1. **방은 장소를 정의하고 콘텐츠는 상황을 정의한다.**
2. 몬스터 수치, 드롭, 보상은 방 문서에 직접 적지 않고 공통 정의를 참조한다.
3. 필수 진행 보상과 무작위 드롭을 분리한다.
4. 새로운 적이 추가되어도 기존 적을 상속하거나 교체할 수 있어야 한다.
5. 모든 콘텐츠에는 고유 ID를 부여해 획득·처치·개방 상태를 저장할 수 있게 한다.
6. 핵심 진행 요소에는 확률을 사용하지 않는다.
7. 초기 버전에는 경제·제작·장비 시스템을 과도하게 늘리지 않는다.

## 2. 방 콘텐츠 슬롯

| 슬롯 | 역할 | 예시 |
| --- | --- | --- |
| 출현 지점 | 적 또는 NPC가 등장할 위치 | 지상 순찰, 천장 매복, 공중 등장 |
| 조우 묶음 | 함께 활성화되는 적 구성 | 기본 적 2 + 원거리 적 1 |
| 보상 지점 | 고정 보상 위치 | 기억 파편, 영구 성장 조각 |
| 소형 획득물 지점 | 회복물·재화 유도선 | 점프 경로를 따라 놓인 재화 |
| 상호작용 지점 | 감정 스킬 대상 | 되감기 구조, 자각 반응 벽 |
| 관문 | 진행 조건 | 보스 처치, 스킬 보유, 숏컷 개방 |
| 체크포인트 | 회복 및 재시작 위치 | 성소, 의자, 기억의 불씨 |

방은 슬롯의 위치와 역할만 가진다. 어떤 적과 아이템이 들어갈지는 콘텐츠 정의에서 선택한다.

## 3. 몬스터 분류

### 3.1 행동 역할

| 역할 | 플레이어에게 요구하는 행동 | 배치 기준 |
| --- | --- | --- |
| 순찰형 | 거리 조절과 기본 공격 | 초반, 좁지 않은 평지 |
| 돌진형 | 회피와 반격 | 긴 다리, 직선 통로 |
| 매복형 | 관찰과 반응 | 천장, 전경 뒤, 비밀 경로 |
| 원거리형 | 이동 우선순위 판단 | 수직 공간, 발판 구간 |
| 방어형 | 후방 이동 또는 스킬 활용 | 좁은 관문, 정예 조우 |
| 환경 연동형 | 감정 스킬 활용 | 각 지역 중후반 |

지역마다 일반 적은 처음에 3종 정도만 사용한다. 한 적이 여러 역할을 동시에 맡기보다 실루엣과
행동 목적이 분명한 적을 조합한다.

### 3.2 등급

| 등급 | 지속 상태 | 보상 |
| --- | --- | --- |
| 일반 | 체크포인트 휴식·사망 후 재생성 | 소량 재화, 낮은 확률 회복물 |
| 정예 | 방 재진입 시 재생성 여부를 개별 설정 | 고정 큰 재화 또는 재료 |
| 중간 보스 | 한 번 처치하면 유지 | 숏컷, 체크포인트, 고정 보상 |
| 지역 보스 | 한 번 처치하면 유지 | 다음 지역 관문, 핵심 파편 |

### 3.3 몬스터 한 종이 가져야 할 정보

- 고유 ID와 표시 이름
- 지역·등급·행동 역할
- 체력, 이동속도, 공격력, 경직 저항
- 사용 가능한 이동 영역
- 감지 거리와 추적 중단 거리
- 공격 예고 시간과 공격 후 빈틈
- 접촉 피해 여부
- 체크포인트 초기화 여부
- 드롭 테이블
- 되감기·숨죽이기·예지·자각 반응
- 사용 가능한 방 태그

## 4. 잔재 초기 몬스터 구성

이름은 제작 중 변경할 수 있는 가칭이다.

| 몬스터 | 역할 | 핵심 행동 | 감정 상호작용 | 권장 방 |
| --- | --- | --- | --- | --- |
| 잔재 보행자 | 순찰형 | 느린 왕복, 짧은 근접 공격 | 되감기 중 접근 압력 | R02, R03, R04 |
| 매달린 손가락 | 매복형 | 천장에서 떨어져 착지 공격 | 예지 확장 시 낙하 위치 표시 가능 | R06, R09, R11 |
| 애도 운반자 | 돌진형 | 직선 예고 후 긴 돌진 | 복원된 벽에 충돌하면 경직 | R07, R09 |
| 굳은 잔재 | 정예·방어형 | 전방 방어, 느린 강공격 | 주변 구조를 복원하면 후방 길 개방 | R09, S2 |
| 손목의 감시자 | 중간 보스 | 원형 전장 순환 공격 | 전장 숏컷 장치를 되감아 빈틈 생성 | R10 |
| 기억의 교수자 | 지역 보스 | 매달린 구조와 지상 공격 전환 | 전장 구조 복원이 공격 패턴과 길을 바꿈 | R12 |

보스전에서 되감기는 단순히 보스에게 피해를 주는 버튼이 아니다. 전장 구조를 바꾸고 안전지대나
공격 기회를 만드는 방식으로 사용한다.

## 5. 아이템 분류

| 분류 | 목적 | 획득 후 유지 |
| --- | --- | --- |
| 회복물 | 현재 탐험 지속 | 즉시 소비 |
| 일반 재화 | 추후 상점·지도·업그레이드 비용 | 사망 후 유지 |
| 영구 성장 조각 | 최대 체력 등 제한적 성장 | 영구 |
| 기억 파편 | 환경 서사와 감정 해금 | 영구 |
| 핵심 능력 | 지역 진행과 백트래킹 | 영구 |
| 열쇠·관문 아이템 | 특정 문 또는 선택 콘텐츠 | 사용 규칙에 따라 유지 |
| 장식·도감 항목 | 수집과 완성도 | 영구 |

초기 제작에서는 회복물, 일반 재화, 영구 성장 조각, 기억 파편, 핵심 능력까지만 사용한다.
장비, 제작 재료, 다단계 상점 경제는 실제 필요가 확인된 뒤 확장한다.

### 5.1 아이템 한 종이 가져야 할 정보

- 고유 ID와 표시 이름
- 분류와 희귀도
- 즉시 사용 또는 보관 여부
- 획득 효과
- 중복 획득 가능 여부
- 저장 여부
- 재생성 규칙
- 획득 조건
- 시각·음향 표시
- 감정 스킬 반응

## 6. 드롭과 보상 규칙

### 6.1 드롭

- 일반 적은 소량 재화를 기본으로 드롭한다.
- 회복물은 낮은 확률 보조 수단으로만 사용한다.
- 플레이어 체력이 낮을 때 회복물 확률을 소폭 보정할 수 있지만, 보스·핵심 보상에는 적용하지 않는다.
- 영구 성장, 기억 파편, 열쇠, 핵심 능력은 무작위 드롭으로 제공하지 않는다.

### 6.2 고정 보상

```text
탐험 발견 → 고정 수집품
선택 전투 → 큰 재화 또는 성장 조각
중간 보스 → 숏컷 + 체크포인트 + 고정 보상
지역 보스 → 다음 지역 관문 + 핵심 파편
재방문 비밀 → 서사 완성 또는 희귀 성장 보상
```

### 6.3 보상 가독성

- 일반 재화는 멀리서도 경로 유도에 사용할 수 있는 작은 빛으로 표시한다.
- 영구 보상은 일반 드롭과 크기·색·소리를 명확히 구분한다.
- 획득할 수 없는 보상을 미리 보여줄 때는 나중에 기억할 수 있는 랜드마크와 함께 배치한다.

## 7. 감정 스킬과 콘텐츠 상호작용

| 대상 | 되감기 | 숨죽이기 | 예지 | 자각 |
| --- | --- | --- | --- | --- |
| 일반 적 | 기본적으로 직접 되돌리지 않음 | 감지 범위 감소 또는 미감지 가능 | 공격 예고 확장 가능 | 숨겨진 상태만 반응 |
| 보스 | 직접 되돌리지 않음 | 패턴별 허용 | 다음 전장 위험 표시 가능 | 서사 연출에만 제한적으로 사용 |
| 드롭 아이템 | 소비 후 복원하지 않음 | 변화 없음 | 변화 없음 | 숨겨진 아이템 노출 가능 |
| 구조물 | 파손→복원 | 좁은 통로 통과 | 미래 위치·붕괴 표시 | 숨겨진 상태·잔상 노출 |
| 관문 | 복원 조건 가능 | 작은 틈 조건 가능 | 타이밍 조건 가능 | 숨겨진 문 조건 가능 |

핵심 규칙은 플레이어가 무한 보상을 만들지 못하게 하는 것이다. 되감기는 소비한 아이템,
획득한 재화, 처치한 일반 적을 복제하거나 되살리지 않는다.

## 8. 활성화와 초기화

### 8.1 방 진입

1. 플레이어가 방 경계를 통과한다.
2. 해당 방의 조우 묶음이 활성화된다.
3. 이미 완료된 일회성 조우는 활성화하지 않는다.
4. 잠금형 전투방이면 출구를 닫고, 완료 시 다시 연다.
5. 보상 조건을 달성하면 고정 보상을 한 번만 생성한다.

모든 방을 잠금형 전투방으로 만들지 않는다. 잔재에서는 중간 보스, 지역 보스, 일부 선택
정예방에만 출구 잠금을 사용한다.

### 8.2 저장해야 하는 상태

- 획득한 기억 파편과 핵심 능력
- 영구 성장 조각
- 처치한 중간 보스·지역 보스
- 완료한 일회성 조우
- 열린 숏컷과 관문
- 복원된 핵심 구조물
- 발견한 방과 비밀방
- 활성화한 체크포인트

일반 적의 현재 위치나 체력, 화면에 남은 소형 드롭은 저장하지 않는다.

---

## 9. 태그를 이용한 확장 규칙

새 콘텐츠는 특정 방 번호에만 묶지 않고 사용 조건을 태그로 표현한다.

예시 태그:

- 지역: `Residue`, `Gaze`, `Fracture`
- 지형: `Ground`, `Vertical`, `Bridge`, `Ceiling`, `Arena`
- 난이도: `Early`, `Mid`, `Late`, `Optional`
- 기능: `Rewind`, `Hush`, `Foresight`, `Awareness`
- 분위기: `Quiet`, `Combat`, `Secret`, `Boss`

새 원거리 적이 `Residue + Vertical + Mid` 태그를 지원한다면, 잔재의 중반 수직 방에 기존
적을 교체하거나 추가하는 방식으로 확장할 수 있다.

## 10. 콘텐츠 추가 절차

### 새 몬스터

1. 행동 역할 하나를 먼저 정한다.
2. 기존 몬스터와 다른 플레이어 대응 행동이 있는지 확인한다.
3. 수치, 드롭, 감정 반응, 사용 태그를 정의한다.
4. 안전한 시험방 하나에 배치한다.
5. 기존 조우 묶음에 한 마리씩 조합한다.
6. 한 화면 적 수와 재도전 시간을 확인한다.

### 새 아이템

1. 소비·재화·영구 성장·서사 중 분류를 정한다.
2. 획득·중복·저장·재생성 규칙을 정한다.
3. 무작위 드롭인지 고정 보상인지 정한다.
4. 기존 보상을 무의미하게 만들지 확인한다.
5. 보상 슬롯에 연결한다.

### 새 지역

1. 지역 감정과 핵심 스킬을 정의한다.
2. 해당 스킬과 반응하는 환경·적 태그를 추가한다.
3. 기존 콘텐츠 중 재사용 가능한 항목을 선택한다.
4. 지역 전용 일반 적은 우선 3종만 만든다.
5. 방별 슬롯에 조우와 보상을 연결한다.

---

## 11. 초기 버전에서 제외

- 무기·방어구 장비 슬롯
- 여러 종류의 제작 재료와 조합식
- 무작위 옵션 아이템
- 적 레벨 자동 스케일링
- 절차 생성형 방과 무작위 적 배치
- 사망 지점 재화 회수
- 복잡한 상점 가격 변동

이 기능들은 콘텐츠 양이 충분히 쌓인 뒤 필요성이 확인될 때 별도 문서로 설계한다.
