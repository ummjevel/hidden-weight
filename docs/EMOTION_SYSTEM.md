## 1. 잔재(殘滓) — 되감기 [죄책감 · 과거]

### 1.1 개념 (확정)
부서지거나 무너진 특정 오브젝트를 가리키고 홀드하면 원래 상태로 되감긴다. 전체 시간 되감기가 아니라 오브젝트 단위로 범위를 좁힌다. 되돌리고 바로잡고 싶어지는 죄책감의 행동 경향을 그대로 능력화한 것이다.

### 1.2 조작 수치 (권장안)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 입력 방식 | 홀드 | 대상 오브젝트에 근접 + 조준 상태 유지 |
| 상호작용 사거리 | 근접 (2타일 이내) | 원거리 되감기는 MVP에서 제외 |
| 채널링 시간 | 1.5초 | 오브젝트 크기와 무관하게 고정값 (구현 단순화) |
| 이동 가능 여부 | 불가 (이동속도 0) | 멈춰서 되돌려야 하는 위험 감수형 스킬 |
| 무적 여부 | 없음 | 채널링 중 피격 시 즉시 캔슬 |
| 피격 시 처리 | 캔슬 + 쿨타임만 소모 | 페널티로 재도전 부담을 준다 |
| 쿨타임 | 2.5초 | 캔슬 여부와 무관하게 사용 즉시 적용 |
| 되감기 지속성 | 영구 | 한 번 되돌리면 이후 계속 유지 (재방문 시에도 유지) |

### 1.3 환경 상호작용 규칙 (권장안)

- 되감기 가능한 오브젝트는 옅은 골드빛 아웃라인으로 상시 표시한다 (자각 없이도 식별 가능해야 진행이 막히지 않는다).
- 되감기 대상 종류 3가지를 제안한다: (1) 무너진 발판 — 되돌리면 밟을 수 있는 플랫폼이 됨, (2) 끊어진 다리/사슬 — 되돌리면 통로가 연결됨, (3) 닫힌 문/게이트 — "예전에 스스로 걸어 잠근 것"이라는 서사 오브젝트, 되돌리면 열림.
- 무드보드 상 잔재 지역의 남색·회갈색 저채도 톤과 어울리도록, 되감기 이펙트는 옅은 골드~앰버 컬러의 파티클로 대비를 준다 (권장안, 7장 색채 방향과 연결).

### 1.4 게이팅 예시 (권장안)

```
시나리오: 무너진 다리로 막힌 구간
1) 플레이어가 다리 앞 도착, 아래는 낭떠러지
2) 다리 잔해를 가리키면 골드 아웃라인 표시
3) 홀드 1.5초 → 다리 복원 → 통과
4) (백트래킹) 자각 해금 후 재방문 시, 복원 전/후 잔상 차이 속에 숨겨진
   벽 뒤 통로가 자각으로만 보임 → 스토리 파편 획득
```

### 1.5 밸런스 노트 / 결정 필요

- 채널링 중 피격 판정 범위(캐릭터 히트박스 유지 vs 축소)는 결정 필요.
- 되감기 대상이 여러 개 동시에 화면에 있을 때 조준 우선순위 규칙 결정 필요 (예: 가장 가까운 것 자동 타겟).

## 2. 응시(凝視) — 숨죽이기 [수치심 · 현재]

### 2.1 개념 (확정)
은신, 축소해서 좁은 틈을 통과하는 회피형 이동 스킬. 융의 그림자 개념과 직접 연결되며, 게임 내 가장 감정적 무게가 큰 구간이다.

### 2.2 조작 수치 (권장안)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 입력 방식 | 홀드로 유지 | 떼면 즉시 해제 |
| 축소 히트박스 | 원래 크기의 55% | 좁은 틈 통과 기준값 |
| 이동속도 | 원래의 65% | 느려지되 완전히 멈추지는 않음 (잔재의 되감기와 대비) |
| 공격 가능 여부 | 불가 | |
| 지속시간 제한 | 없음 (MVP) | 별도 스태미나 게이지 두지 않음 |
| 해제 시 무적프레임 | 0.2초 | 원래 크기로 돌아오는 순간 피격당하는 것 방지 |

### 2.3 "시선(눈)" 기믹 상세 (권장안)

| 항목 | 값 |
| --- | --- |
| 감지 방식 | 시야각 90도 부채꼴 + 반경 4타일 |
| 감지 시 반응 | 경보 이펙트(눈 확대) → 0.5초 후 근처 위협 활성화(가시/추적 등, 결정 필요) |
| 숨죽이기 중 처리 | 감지 시스템이 완전히 무시함 (범위 안에 있어도 미감지) |
| 순찰 패턴 | 고정형(한자리 응시) / 회전형(시야각 회전) 두 종류를 권장 — 스테이지 난이도 조절용 |

### 2.4 자각 해금 트리거 (확정 위치, 연출은 권장안)

응시 지역 진행 중 특정 지점(권장: 지역 후반부, 가장 큰 "눈" 모티브 오브제 앞)에서 자각이 자동으로 해금된다. 연출은 대사 없이, 숨어 있던 캐릭터가 처음으로 정면을 응시하는 동작으로 표현한다 (결정 필요: 정확한 트리거 지점과 애니메이션 길이).

### 2.5 게이팅 예시 (권장안)

```
시나리오: 감시자의 회랑
1) 회전형 "눈" 3개가 순차적으로 통로를 훑는 구간
2) 숨죽이기로 축소 + 감속 이동하며 사각지대로 이동
3) 최종 지점에 거대 눈 오브제 → 자각 해금 컷씬
4) 이후 통로에서는 자각으로 "눈"의 다음 회전 타이밍을 미리 감지 가능
```

### 2.6 밸런스 노트 / 결정 필요

- 이동속도 65%가 회전형 눈의 순찰 주기와 맞는지는 레벨 프로토타입에서 검증 필요.
- 감지 시 즉시 처치(사망)인지 데미지인지 결정 필요 — 메트로배니아 특성상 데미지 후 무적프레임 방식을 권장.

## 3. 균열(龜裂) — 예지 [불안 · 미래]

### 3.1 개념 (확정)
지정한 범위 안에서 몇 초 뒤 일어날 상태를 반투명 잔상으로 짧게 미리 보여준다. 불안은 아직 오지 않은 위협을 미리 걱정하는 감정이라는 특성을, "불안하기 때문에 위험을 먼저 보고 대비할 수 있다"는 능력으로 뒤집었다.

### 3.2 조작 수치 (권장안)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 입력 방식 | 탭 | 잔재·응시의 홀드와 리듬을 다르게 가져감 |
| 잔상 표시 지속시간 | 2.5초 | |
| 예지 대상 선정 | 화면 내 "예지 가능" 오브젝트 중 최근접 자동 타겟 | 수동 조준은 MVP에서 제외 (권장안) |
| 쿨타임 | 4초 | 세 스킬 중 가장 길게 설정 — 탭 입력이라 남용 방지 목적 |
| 표시 정보 유형 | 이동 발판의 도착 위치 / 붕괴형 바닥의 붕괴 후 형태 | 확장안: 함정 발동 타이밍 (보류) |

### 3.3 자각의 불안정성 — 구체 규칙 (확정, 이번 문서로 명문화)

균열 지역에서 자각은 실제 함정·거짓 요소의 존재 여부와 무관하게 **항상 "이상 없음" 판정만 표시한다.** 즉 이 지역에서는 자각이 사실상 무력화되어 있으며, **예지만이 유일하게 신뢰 가능한 정보원**이 된다. 이 규칙은 플레이어가 "감각을 못 믿는" 것을 스토리로 설명하지 않고 규칙으로 체감하게 만든다.

- 예외: 엔딩(3.4절, GAME_DESIGN.md)의 침실 시퀀스는 균열 지역이 아닌 별도 공간이므로 이 무력화 규칙이 적용되지 않는다. 1단계에서 자각이 정상 작동해 흔적을 잡아내는 것과 모순되지 않는다.

### 3.4 게이팅 예시 (권장안)

```
시나리오: 흔들리는 정원
1) 겉보기엔 안전해 보이는 발판들이 늘어선 구간 (자각을 써도 전부 "안전" 판정)
2) 예지를 탭하면 다음 발판이 밟는 순간 무너질 것이 잔상으로 보임
3) 예지 정보만 믿고 우회 경로로 이동해야 통과 가능
```

### 3.5 밸런스 노트 / 결정 필요

- 예지 쿨타임 4초가 플랫포밍 리듬과 맞는지 프로토타입 검증 필요.
- 자동 타겟팅 우선순위(가장 위험한 오브젝트 우선 vs 가장 가까운 오브젝트 우선) 결정 필요.

## 4. 자각(自覺) — 공통 시스템 상세

### 4.1 정의 (확정, GAME_DESIGN.md 4.3절 동일)
감각을 확장해 탐지하는 도구가 아니라, 지금 느끼는 감정을 정면으로 끌어안는 행위 그 자체. 선명해지는 시야는 그 결과일 뿐이다.

### 4.2 조작 수치 (권장안, 신규 확정 수치)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 입력 방식 | 홀드 | |
| 사용 중 이동속도 | 원래의 70% | 잔재(0%)·응시(65%)보다 빠름 — "계속 나아가며 품는 현재" |
| 지속시간 제한 | 없음 (MVP) | 별도 자원 게이지 두지 않음 |
| 해금 지점 | 응시 지역 (2.4절) | |

### 4.3 지역별 감지 방식 요약 (확정)

| 지역 | 감지 내용 | 신뢰도 |
| --- | --- | --- |
| 잔재 (해금 전) | 사용 불가 | — |
| 잔재 (백트래킹 후) | 되감기 전/후 오브젝트 잔상 차이 | 신뢰 가능 |
| 응시 | 은신 중에만 보이는 숨겨진 표식 | 신뢰 가능 |

## 5. 확장 — 기쁨 (권장안, MVP 이후)

| --- | --- |
| 스킬명 (가제) | 도약/활공 |
| 효과 | 이동속도 +20%, 점프력 +30%, 공중에서 짧은 활공 가능 |

## 7. 수치 밸런스 종합표 (권장안)

| 스킬 | 입력 | 지속/채널링 | 이동배율 | 쿨타임 | 무적 |
| --- | --- | --- | --- | --- | --- |
| 되감기 (잔재) | 홀드 | 1.5초 | 0% | 2.5초 | 없음 |
| 숨죽이기 (응시) | 홀드 유지 | 무제한 | 65% | — | 해제 시 0.2초 |
| 예지 (균열) | 탭 | 2.5초 표시 | 100% | 4초 | — |
| 자각 (공통) | 홀드 | 무제한 | 70% | — | — |

이 표는 세 핵심 스킬 + 자각의 이동배율이 0% → 65% → 70% → 100%(예지, 순간형이라 이동 제약 없음) 순으로 점점 가벼워지도록 의도적으로 설계했다.

## 8. 결정 필요 사항 정리

1. 되감기 채널링 중 히트박스 처리 (1.5절)
2. 되감기 동시 타겟 우선순위 (1.5절)
3. "시선" 감지 시 데미지/즉사 여부 (2.6절)
4. 자각 해금 컷씬 정확한 트리거 지점과 길이 (2.4절)
5. 예지 자동 타겟팅 우선순위 규칙 (3.5절)
6. 위 수치 전체 — 프로토타입 플레이테스트 후 조정
