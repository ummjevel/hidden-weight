## 0. 문서 사용법

이 문서는 잔재 지역을 실제 플레이 가능한 방으로 제작할 때 사용하는 기준이다. 방마다
다음 항목을 고정한다.

- 방 크기와 출입구
- 바닥·발판·낙하 구간
- 적의 종류와 등장 순서
- 되감기 대상과 사용 목적
- 안전지대·체크포인트·보상
- 실패 시 복구 위치
- 첫 방문과 재방문 변화
- 구현에 필요한 기존 기능과 신규 기능

좌표는 각 방의 왼쪽 아래를 `(0, 0)`으로 보는 **방 로컬 좌표**다. 실제 씬의 전역 좌표는
방을 배치할 때 변환한다. 모든 수치는 플레이테스트 전 제작 기준이며, 최종 충돌 지형은
±0.5유닛 범위에서 조정할 수 있다.

## 1. 공통 이동 기준

### 1.1 현재 플레이어 기준값

| 항목 | 값 |
| --- | ---: |
| 플레이어 충돌 크기 | 0.8 × 1.4유닛 |
| 걷기 / 달리기 | 초당 6 / 9유닛 |
| 점프 초기속도 | 14 |
| 대시 거리 / 지속시간 | 4유닛 / 0.15초 |
| 대시 재사용 | 0.8초 |
| 벽 슬라이드 | 초당 2유닛 하강 |
| 벽점프 속도 | 가로 9 / 세로 13 |
| 최대 체력 | 3 |
| 카메라 세로 범위 | 12유닛 |
| 16:9 카메라 가로 범위 | 약 21.3유닛 |

### 1.2 발판 간격 등급

아래 값은 점프가 시작되는 발판 끝과 착지 발판 시작 사이의 수평 거리다.

| 등급 | 수평 간격 | 높이 차 | 사용처 |
| --- | ---: | ---: | --- |
| 안전 | 1.5~2.5 | ±1.0 이하 | 첫 소개, 전투 중 필수 이동 |
| 표준 | 2.5~3.5 | +1.5 / -2.0 이하 | 일반 주 동선 |
| 숙련 | 3.5~4.5 | +2.0 / -3.0 이하 | 후반 주 동선, 선택 보상 |
| 대시 필수 | 4.5~6.0 | +1.0 이하 | 대시를 명확히 요구하는 선택 구간 |

- 필수 주 동선에서 수평 5유닛을 넘는 점프를 연속으로 두지 않는다.
- 화면 밖 착지를 요구하지 않는다. 착지면의 최소 1.5유닛은 점프 전에 보여야 한다.
- 폭 1유닛 미만 발판은 주 동선이 아니라 선택 보상에만 사용한다.
- 벽점프 굴뚝 폭은 3~5유닛로 잡고, 첫 굴뚝은 4유닛을 권장한다.
- 낙하 후 즉시 사망하는 구간은 보스전과 선택 고난도 이외에는 사용하지 않는다.

### 1.3 난이도 단계

| 단계 | 의미 | 허용 실패 압력 |
| --- | --- | --- |
| D0 | 안전·관찰 | 사망 요소 없음 |
| D1 | 단일 행동 학습 | 실패 시 같은 화면에서 즉시 재시도 |
| D2 | 두 행동 결합 | 체력 1 피해 또는 10초 이내 복귀 |
| D3 | 지역 표준 시험 | 적+지형 결합, 20초 이내 복귀 |
| D4 | 주 동선 후반·중간 보스 | 연속 2~3행동, 체크포인트 2분 이내 |
| D5 | 선택 고난도·지역 보스 | 숙련 요구, 체크포인트 3분 이내 |

### 1.4 안전지대 규칙

- 안전지대 최소 폭은 3유닛이다.
- 새 적을 처음 보여주는 위치와 실제 조우 지점 사이에 2초 이상 관찰 시간을 둔다.
- 어려운 점프 직후 2유닛 이상의 착지 여유를 둔다.
- 체력 3 기준으로 필수 경로에서는 연속 피해 위험을 최대 2회까지만 둔다.
- 카메라 전환 직후 1.5초 동안 적이 플레이어를 바로 공격할 수 없게 배치한다.

## 2. 공통 요소 구현 목록

| 일반 지형 | Tilemap + Collider |

| 기억 파편 | 현재 StoryFragment / HiddenFragment |

### 2.2 구현 전에 추가가 필요한 공통 요소

| 요소 | 필요한 역할 | 우선순위 |
| --- | --- | --- |
| 방별 낙하 복귀 지점 | 구덩이 추락 시 해당 방의 안전 발판으로 복귀 + 체력 1 피해 | 필수 |
| 조우 관리자 | 방 진입, 적 묶음 활성화, 전투 종료, 문 개방 | 필수 |
| 일회성 조우 상태 | 정예·중간 보스 완료 상태 저장 | 필수 |
| 위험 영역 | 가시·심연·압착 등에 공통 피해와 복귀 처리 | 필수 |
| 숏컷 장치 | 사슬다리·승강기·문 개방 상태 저장 | 필수 |
| 고정 보상 상자 | 조건 달성 후 한 번만 보상 생성 | 필수 |
| 적 행동 모듈 | 돌진, 매복, 방어 행동을 교체 가능하게 구성 | 필수 |
| 보스 전장 관리자 | 보스 단계, 전장 되감기 대상, 승리 처리 | 보스 제작 시 |
| 방 발견 상태 | 지도에 방문한 방 기록 | 지도 UI 제작 시 |

신규 기능의 구체적인 코드 구조는 별도 구현 계획에서 정한다. 이 문서에서는 각 방이 어떤
기능을 요구하는지만 고정한다.

## 3. R01 — 입구 경계

### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 26 × 14 |
| 난이도 | D0 |
| 입구 / 출구 | 서쪽 `(0, 2)` / 동쪽 `(26, 2)` |
| 전투 | 없음 |
| 핵심 기능 | 체크포인트, 랜드마크 소개 |

### 지형

- `x=0~26, y=0~2`를 연속 바닥으로 만든다.
- `x=8~11`에 높이 1유닛 둔덕, `x=15~18`에 높이 2유닛 계단을 둔다.
- 바닥 아래로 떨어지는 공간은 만들지 않는다.
- `x=20` 이후 배경에 R03 손바닥과 R10 감시탑 실루엣을 동시에 보인다.

### 배치

- 플레이어 시작: `(3, 3)`
- 체크포인트: `(5, 3)`
- 작은 재화 3개: 계단을 따라 `(15, 4)`, `(16.5, 4.5)`, `(18, 5)`
- 전투·되감기 대상·무너지는 발판은 배치하지 않는다.

### 플레이 의도

플레이어가 캐릭터 크기와 배경 규모를 비교하고 다음 목표를 눈으로 확인하는 방이다. 이동을
막는 요소를 두지 않는다. 체크포인트 사용 후 동쪽으로 자연스럽게 이동하면 된다.

### 실패·검증

- 실패 가능 요소 없음
- 정지 상태에서도 다음 출구가 화면 구도상 명확해야 한다.
- 벤치마킹: 할로우 나이트식 지역 진입의 정적, 오리식 랜드마크 선공개

## 4. R02 — 애도교

### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 28 × 14 |
| 난이도 | D1→D2 |
| 입구 / 출구 | 서쪽 `(0, 2)` / 동쪽 `(28, 3)` |
| 전투 | 잔재 보행자 2 |
| 핵심 기능 | 안전한 낙하, 첫 적 분리 학습 |

### 지형

1. `x=0~8` 안전한 평지
2. `x=8~13` 끊어진 상부 다리
3. 다리 아래 `y=1`에 폭 7유닛의 복구용 하부 통로
4. `x=15~20` 높이 1.5유닛의 두 번째 발판
5. `x=22~28` 출구 평지

첫 다리에서 떨어져도 죽지 않고 하부 통로로 진행한다. 상부를 달려 넘으면 작은 보상을 얻고,
실패하면 더 긴 안전 경로를 이용한다.

### 적과 보상

- 잔재 보행자 A: `(6, 3)`, 평지 4유닛 범위 순찰
- 잔재 보행자 B: `(21, 4)`, 두 번째 발판 위 순찰
- 두 적은 동시에 플레이어를 감지하지 못하게 10유닛 이상 분리한다.
- 상부 다리 끝에 재화 5개
- 방 끝에 소형 회복물 1개

### 실패·복구

- 다리 추락: 피해 없음, 하부 통로로 연결
- 적 피격: 뒤쪽 안전 평지로 넉백되도록 적 방향 배치
- 플레이어는 “실패해도 다른 길이 된다”는 규칙을 배운다.

### 검증

- 첫 적을 공격하지 않고 점프로 지나갈 수 있어야 한다.
- 두 적과 동시에 싸우게 되는 위치가 없어야 한다.
- 벤치마킹: 할로우 나이트 초반의 분리된 단일 적 소개, 셀레스트의 실패를 경로로 바꾸는 학습

## 5. R03 — 손바닥 광장

### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 30 × 18 |
| 난이도 | D1 |
| 입구 | 서쪽 `(0, 2)` |
| 첫 방문 출구 | 남동쪽 R04 `(27, 1)` |
| 잠긴 연결 | 북서 R05 숏컷 A, 상부 R08 숏컷 B |
| 전투 | 잔재 보행자 1, 선택 |

### 지형과 길 안내

- 중앙 `x=10~20, y=2~5`를 넓은 손바닥 형태의 안전 광장으로 만든다.
- 남동쪽 길은 낮은 재화 줄과 밝은 골드 흔적으로 강조한다.
- 북서쪽 숏컷 A는 끊어진 사슬다리로 보인다.
- 상부 숏컷 B는 멈춘 승강기와 R08의 푸른 빛으로 보인다.
- 플레이어는 두 막힌 길을 직접 만져볼 수 있지만 통과할 수 없다.

### 배치

- 잔재 보행자 1: 중앙보다 아래인 `(17, 3)`, 우회 가능
- 지도 랜드마크 지점: `(12, 5)`
- R05 이후 복원 가능한 숏컷 A 장치: `(6, 8)`
- R08 이후 내려오는 승강기 정지점: `(23, 5)`

### 첫 방문과 변화

| 시점 | 변화 |
| --- | --- |
| 첫 방문 | R04만 개방 |
| R05 완료 | 북서 사슬다리 복원, R05와 직결 |
| R08 완료 | 상부 승강기 작동, R08과 직결 |
| 균열 이후 | 이미 열린 연결을 이용해 R11로 빠르게 이동 |

### 검증

- 텍스트 없이도 첫 방문 출구가 가장 밝고 낮은 길로 보여야 한다.
- 잠긴 두 연결은 지도 기억을 만들 만큼 눈에 띄어야 한다.
- 벤치마킹: 할로우 나이트식 중앙 허브와 나중에 열리는 물리적 연결

## 6. R04 — 매몰된 하층 폐허

### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 24 × 22 |
| 난이도 | D2 |
| 입구 / 출구 | 북서 `(2, 20)` / 남동 R05 `(22, 2)` |
| 비밀 연결 | S1 입구 `(7, 5)` |
| 전투 | 잔재 보행자 2 |
| 핵심 기능 | 수직 하강, 선택 탐색, 무너지는 발판 소개 |

### 구간

1. 상층 관찰대 `y=18~20`
2. 중앙의 지그재그 하강 발판 `y=8~17`
3. 하층 안전 바닥 `y=2~5`
4. S1으로 이어지는 부서진 바닥 `x=6~9, y=6`

발판 간 높이는 2~3유닛, 수평 차이는 2.5유닛 이하로 둔다. 첫 무너지는 발판은 착지 후
0.6초 안에 다음 안전 발판으로 이동할 수 있게 하고, 실패하면 하층으로 떨어질 뿐 피해를
주지 않는다.

### 적 배치

- 잔재 보행자 A: 중층 폭 5유닛 발판, 플레이어가 위에서 먼저 관찰
- 잔재 보행자 B: 하층, S1 입구 반대편
- 발판 이동 도중 공격받지 않게 적의 순찰 끝과 발판 가장자리 사이에 1유닛 벽턱을 둔다.

### 비밀 암시

- S1 위 바닥에서 먼지가 아래로 떨어진다.
- 보행자 B가 가끔 S1 방향을 바라보도록 한다.
- 아래에서 낮은 종소리를 재생한다.

### 실패·복구

- 모든 상층 추락은 하층 안전 바닥으로 연결
- 다시 올라가는 벽점프 통로는 폭 4유닛, 높이 8유닛
- 낙하 복구 최장 시간 15초

### 검증

- 무너지는 발판을 모두 밟지 않아도 주 동선 통과 가능
- S1을 못 찾아도 진행에 손해가 없음
- 벤치마킹: 오리의 수직 경로 가독성, 할로우 나이트의 소리로 암시하는 비밀

## 7. S1 — 납골당

### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 18 × 14 |
| 난이도 | D3 선택 |
| 입구 / 출구 | 상부 `(5, 14)` / 동일 경로 복귀 |
| 전투 | 없음 |
| 핵심 기능 | 짧은 정밀 이동 퍼즐 |

### 퍼즐

- 세 개의 폭 1.5유닛 발판을 `2.5`, `3`, `3.5`유닛 간격으로 순차 배치한다.
- 마지막 발판만 밟은 뒤 0.6초에 무너진다.
- 실패 시 아래 안전 바닥으로 떨어지고 8초 안에 시작점으로 복귀한다.
- 즉사나 체력 피해는 사용하지 않는다.

### 보상

- 끝 지점에 기억 파편 1개와 큰 재화 묶음
- 파편을 얻으면 출구 쪽 사다리형 벽이 열려 복귀 시간이 5초로 줄어든다.

### 검증

- 대시 없이도 통과 가능, 대시를 쓰면 여유가 커져야 한다.
- 카메라는 다음 발판을 항상 보여야 한다.
- 벤치마킹: 셀레스트식 짧은 도전과 빠른 재시도

## 8. R05 — 되감기 성소

### 제작 정보

| 항목 | 값 |
| --- | --- |

- 바닥 그림자와 사슬 소리로 1초 이상 예고
- 무너진 안전 발판을 되감으면 낙하 충격을 피할 높은 지점을 만든다.

#### 3단계 — 되돌릴 수 없는 것

- 체력 30% 아래에서 기존 공격을 두 개씩 조합
- 복원한 안전 발판 중 하나가 다시 파손되지만, 나머지 하나는 유지
- 새로운 공격은 추가하지 않고 공간 제약만 늘린다.

### 실패·재도전

- R10 체크포인트에서 R12 입구까지 숏컷 사용 시 2분 이내
- R11의 일반 전투는 없으므로 재도전 중 소모를 강요하지 않는다.
- 보스 입장 연출은 첫 도전만 전체 재생하고 이후 1초 이하로 축소한다.

### 승리

1. 보스 처치 상태 영구 저장
2. 핵심 기억 파편 생성
3. 전장 위험 비활성화
4. 응시 지역 통로 개방
5. R11로 되돌아갈 길도 유지

### 검증

- 첫 도전에서도 모든 공격을 보고 학습할 가능성이 있어야 한다.
- 목표 평균 재도전은 5~10회
- 되감기를 쓰면 유리하지만, 채널링 중 공격받는 위험이 명확해야 한다.
- 벤치마킹: 할로우 나이트의 명확한 패턴 학습, 셀레스트식 짧아지는 재도전 동선

## 18. 전체 난이도 곡선

```text
D0 R01
 └─ D1~2 R02
      └─ D1 R03
           ├─ D2 R04 ─ D3 S1
           └─ D0~2 R05
                    └─ D2~3 R06 ─ D5 S2
                              └─ D3 R07
                                   └─ D3 R08
                                        └─ D4 R09
                                             └─ D4 R10
                                                  └─ D1~3 R11 ─ D0 S3
                                                            └─ D5 R12
```

주 동선은 한 번에 한 단계씩만 상승한다. D4 이후 R11에서 난도를 의도적으로 낮춰 보스 전
피로를 회복시킨다. D5 선택방 S2는 언제든 포기하고 나올 수 있어야 한다.

## 19. 플레이테스트 체크리스트

### 이동

- 각 필수 점프를 걷기·달리기·대시 중 어떤 방식으로 통과하는지 기록한다.
- 3회 연속 실패하는 지점은 착지 폭, 카메라, 적 압력을 먼저 조정한다.
- 낙하 복구 시간이 문서 기준을 넘는지 측정한다.

### 전투

- 새 적을 처음 만난 방에서 공격 예고를 읽을 수 있는지 확인한다.
- 적 두 종류가 동시에 공격해 피할 수 없는 조합이 생기지 않는지 확인한다.
- 피격 넉백이 낙사로 이어지는 위치를 기록한다.

### 길 찾기

- R03 첫 방문에서 30초 안에 R04 방향을 찾는지 확인한다.
- R05와 R08 숏컷을 연 뒤 플레이어가 R03과 연결되었음을 인식하는지 확인한다.
- 균열 클리어 후 힌트 없이 S3 위치를 떠올리는 플레이어 비율을 확인한다.

### 목표 수치

| 항목 | 목표 |
| --- | ---: |
| 주 동선 첫 클리어 | 30~40분 |
| 선택 콘텐츠 포함 | 40~50분 |
| 일반 방 평균 사망 | 0~1회 |
| R09 평균 사망 | 1~3회 |
| R10 평균 도전 | 3~6회 |
| S2 평균 도전 | 5~10회 |
| R12 평균 도전 | 5~10회 |
| 보스 재도전 이동 | 최대 2분 |
