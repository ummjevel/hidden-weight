## 0. 목적과 우선순위

이 문서는 몽환의 우주, 잔재, 응시, 균열, 엔딩을 같은 공간 단위와 난이도 언어로 제작하기
위한 공통 기준이다. 지역별 문서와 충돌할 때 우선순위는 다음과 같다.

1. `GAME_DESIGN.md`의 확정 서사·진행 순서
2. `EMOTION_SYSTEM.md`의 스킬 규칙
3. 지역 `LEVEL_DESIGN`의 경험·방 연결 구조
4. 지역 `ROOM_IMPLEMENTATION`의 좌표·배치 수치
5. 이 문서의 공통 권장값

좌표와 전투 수치는 플레이테스트 전 블록아웃 기준이다. 감정 스킬의 의미, 필수 학습 순서,
방 연결, 핵심 파편 위치는 수치 조정으로 바꾸지 않는다.

## 1. 좌표·카메라·룸 연결

### 1.1 로컬 좌표

- 각 방의 왼쪽 아래를 `(0, 0)`으로 둔다.
- 좌표 1은 Unity 월드 1유닛이다.
- 문서 좌표는 오브젝트 피벗 기준이며 최종 콜라이더는 ±0.5유닛 안에서 조정할 수 있다.
- 출구 좌표는 플레이어가 서는 바닥 높이가 아니라 연결 포털의 중심 좌표다.
- 서로 연결되는 두 방은 출구 방향, 바닥 높이, 실루엣을 일치시킨다.

### 1.2 카메라

| 항목 | 기준 |
| --- | --- |
| 화면 비율 | 16:9 |
| 기본 가시 범위 | 가로 약 21.3 × 세로 12유닛 |
| 작은 방 | 한 화면 고정 또는 약한 데드존 추적 |
| 큰 가로 방 | 플레이어 추적 + 방 경계 Clamp |
| 큰 세로 방 | 구간별 카메라 앵커 전환 |
| 전환 시간 | 일반 0.35초, 서사 방 0.6초, 추락 복귀 0.15초 |
| 진입 보호 | 전환 완료 뒤 1.5초 또는 첫 입력 전까지 적 선제공격 금지 |

혼합형 카메라를 기본으로 한다. 한 화면 안에서 기믹의 원인과 결과를 함께 읽어야 하는 퍼즐·
보스방은 고정 구도를 우선하고, 길이가 24유닛을 넘는 탐색방은 추적 카메라를 사용한다.

### 1.3 출입구 표기

| 표기 | 의미 |
| --- | --- |
| W / E | 서쪽 / 동쪽 수평 연결 |
| NW / NE | 상부 좌우 연결 |
| SW / SE | 하부 좌우 연결 |
| U / D | 승강기·수직 통로 |
| S | 비밀방 연결 |

입구에서 필수 위험까지 최소 4유닛의 안전 바닥을 둔다. 출구 앞 3유닛은 전투가 끝난 뒤
안전해야 하며, 화면 전환 경계에 적 순찰 범위가 닿지 않게 한다.

## 2. 플레이어·플랫포밍 기준

### 2.1 현재 플레이어 기준값

| 항목 | 값 |
| --- | ---: |
| 충돌 크기 | 0.8 × 1.4유닛 |
| 걷기 / 달리기 | 초당 6 / 9유닛 |
| 점프 초기속도 | 14 |
| 대시 거리 / 지속시간 | 4유닛 / 0.15초 |
| 대시 쿨타임 | 0.8초 |
| 벽 슬라이드 | 초당 2유닛 하강 |
| 벽점프 | 가로 9 / 세로 13 |
| 기본 공격 | 피해 1, 반경 1.2, 90도, 쿨타임 0.35초 |
| 최대 체력 | 3 |

### 2.2 발판 간격

| 등급 | 수평 간격 | 높이 차 | 사용처 |
| --- | ---: | ---: | --- |
| 안전 | 1.5~2.5 | ±1.0 이하 | 첫 소개, 전투 중 필수 이동 |
| 표준 | 2.5~3.5 | +1.5 / -2.0 이하 | 일반 주 동선 |
| 숙련 | 3.5~4.5 | +2.0 / -3.0 이하 | 후반, 선택 보상 |
| 대시 필수 | 4.5~6.0 | +1.0 이하 | 대시를 명확히 시험하는 구간 |

- 필수 주 동선에서 5유닛 초과 점프를 연속 배치하지 않는다.
- 착지면 최소 1.5유닛을 도약 전에 화면에 보여준다.
- 폭 1유닛 미만 발판은 선택 콘텐츠에만 쓴다.
- 첫 벽점프 굴뚝은 폭 4유닛, 이후 3~5유닛으로 만든다.
- 어려운 점프 직후 폭 2유닛 이상의 착지 여유를 둔다.

## 3. 난이도·긴장과 이완

| 단계 | 의미 | 실패 압력 |
| --- | --- | --- |
| D0 | 안전·관찰·서사 | 사망 요소 없음 |
| D1 | 단일 행동 학습 | 같은 화면에서 즉시 재시도 |
| D2 | 두 행동 결합 | 체력 1 피해 또는 10초 내 복귀 |
| D3 | 지역 표준 시험 | 적+지형, 20초 내 복귀 |
| D4 | 후반·중간 보스 | 연속 2~3행동, 체크포인트 2분 내 |
| D5 | 선택 고난도·지역 보스 | 숙련 요구, 체크포인트 3분 내 |

모든 지역은 다음 리듬을 유지한다.

```text
관찰 → 단일 학습 → 안전한 확인 → 두 요소 결합 → 짧은 휴식
→ 이동·전투 결합 → 중간 시험 → 정적 → 종합 시험 → 해소
```

새 기믹과 새 적을 같은 순간 처음 소개하지 않는다. D3 이상의 방 뒤에는 적이 없거나 우회할
수 있는 20~40초 구간을 둔다. 체크포인트는 실패 직전의 긴장을 지우는 장소가 아니라, 학습한
내용을 다시 시도할 비용을 줄이는 장소로 배치한다.

## 4. 전투 블록아웃 수치

### 4.1 공통 원칙

- 일반 적의 모든 직접 공격은 체력 1 피해다.
- 즉사 공격은 MVP에서 사용하지 않는다.
- 플레이어 공격 1회를 1타로 센다.
- 일반 적은 2~4타, 정예는 7~9타를 기본으로 한다.
- 같은 화면의 일반 적은 보통 1~3마리, 최대 4마리다.
- 적 두 종류가 동시에 공격할 때 공격 예고가 겹치지 않는 0.4초 이상의 빈틈을 보장한다.
- 피격 무적 중 다른 공격이 중첩되어 체력 2가 한 번에 사라지지 않게 한다.

### 4.2 역할별 권장값

| 역할 | 체력 | 이동속도 | 감지 | 공격 사거리 | 예고 | 공격 후 빈틈 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 순찰·근접형 | 2 | 1.8~2.2 | 5 | 1.4 | 0.55초 | 0.8초 |
| 매복형 | 2 | 착지 후 1.5 | 그림자 6 | 1.8 | 1.0초 | 1.0초 |
| 돌진형 | 3 | 2 / 돌진 8 | 7 | 직선 7 | 0.8초 | 1.3초 |
| 지원·원거리형 | 3 | 1.2 | 8 | 6~8 | 0.9초 | 1.2초 |
| 정예·방어형 | 8 | 1.5 | 7 | 2.0 | 0.9초 | 1.2~1.8초 |
| 중간 보스 | 18 | 패턴별 | 전장 | 패턴별 | 0.7초 이상 | 0.8초 이상 |
| 지역 보스 | 30 | 패턴별 | 전장 | 패턴별 | 0.8초 이상 | 단계별 명시 |

적 이름별 세부 반응은 지역 문서를 따른다. 이 표는 회색 박스 플레이테스트용 시작값이며,
처치 시간보다 공격 판독과 이동 압력이 우선이다.

### 4.3 리스폰

| 대상 | 사망 후 | 체크포인트 휴식 | 지역 재진입 |
| --- | --- | --- | --- |
| 일반 적 | 재생성 | 재생성 | 재생성 |
| 정예 | 처치 상태 유지 | 유지 | 유지 |
| 중간·지역 보스 | 처치 상태 유지 | 유지 | 유지 |
| 정예·보스 고정 보상 | 획득 상태 유지 | 유지 | 유지 |
| 소형 회복물 | 방 규칙에 따라 재생성 | 재생성 가능 | 재생성 가능 |
| 핵심 구조·숏컷·파편 | 유지 | 유지 | 유지 |

정예는 최초 처치 뒤 영구 제거한다. 해당 방이 비어 보이지 않도록 약한 일반 적 또는 비전투
환경 변화로 대체할 수 있지만 고정 보상은 다시 생성하지 않는다.

## 5. 실패·복구

- 일반 낙사: 체력 1 피해 + 같은 방의 최근 안전 앵커로 복귀한다.
- 첫 기믹 소개 실패: 피해 없이 하부 경로나 직전 발판으로 복귀한다.
- 복귀 후 0.8초 무적과 입력 가능한 상태를 보장한다.
- 낙하 복구 앵커에는 적 공격 범위가 닿지 않는다.
- 방 초기화가 필요한 퍼즐은 플레이어가 3초 안에 재시작할 수 있는 장치를 둔다.
- 일반 방 재도전 20초, 중간 보스 입구 30초, 지역 보스 3분 이내를 상한으로 한다.

## 6. 방별 문서 필수 항목

각 방은 아래 항목을 빠짐없이 가진다.

1. 방 크기, 난이도, 예상 시간
2. 입구·출구·비밀 연결 좌표
3. 한 문장 경험 목표와 재미 요소
4. ASCII 블록아웃
5. 지형 구간과 카메라 방식
6. 적·기믹·보상 좌표 또는 범위
7. 진입부터 퇴장까지의 조우 순서
8. 실패 복구 앵커와 재시도 시간
9. 첫 방문·재방문·클리어 후 변화
10. 구현 슬롯과 완료 검증 조건

### 6.1 ASCII 범례

| 기호 | 의미 | 기호 | 의미 |
| --- | --- | --- | --- |
| `P` | 플레이어 진입 | `>` | 주 출구 |
| `#` | 고정 지형 | `=` | 발판·다리 |
| `~` | 낙하·위험 | `E` | 일반 적 |
| `X` | 정예·보스 | `K` | 체크포인트 |
| `A` | 감정 스킬 대상 | `R` | 복귀 앵커 |
| `$` | 일반 보상 | `M` | 기억 파편 |
| `S` | 비밀 연결 | `L` | 숏컷·잠긴 연결 |

ASCII는 정확한 타일 수가 아니라 지형 관계와 화면 흐름을 보여준다. 실제 치수는 제작 정보와
좌표표를 우선한다.

## 7. 아트 레이어·가독성

| 레이어 | 역할 | 충돌 |
| --- | --- | --- |
| Far | 랜드마크, 지역 진행 방향 | 없음 |
| Mid | 건축·서사 오브젝트 | 없음 |
| Gameplay | 플레이어, 적, 발판, 기믹 | 있음 |
| Foreground | 프레이밍, 깊이감 | 없음 |
| VFX | 위험 예고, 감정 반응 | 판정과 동기화 |

- Gameplay 지형 가장자리에는 지역 공통 명도선을 둔다.
- 전경은 플레이어나 위험 판정을 0.5초 넘게 완전히 가리지 않는다.
- 위험 예고 색은 배경 팔레트와 명도 차이 20% 이상을 확보한다.
- 각 방에는 다른 방과 구분되는 실루엣 요소를 최소 하나 둔다.
- 다음 목적지는 도달 전에 Far 또는 Mid 레이어에서 한 번 보여준다.

## 8. 구현 전 승인 게이트

문서 공유 후 다음 순서로 승인한다.

1. 방 연결과 핵심 사건 위치
2. 회색 박스의 크기·입출구·카메라
3. 기믹과 적 조우 순서
4. 실패 복구와 체크포인트 거리
5. 보상·기억 파편 위치
6. 아트 레이어와 랜드마크

1~2가 승인되기 전에는 완성 아트를 배치하지 않는다. 3~4가 승인되기 전에는 보스 수치와
연출 타이밍을 고정하지 않는다.
