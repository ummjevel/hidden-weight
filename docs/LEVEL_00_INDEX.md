## 0. 확정 범위

```text
몽환의 우주(튜토리얼)
  → 잔재 12+3방
  → 응시 12+3방
  → 균열 12+3방
  → 잔재 S3 백트래킹
  → 경계 허브
  → 거짓 깨어남
  → 진짜 각성
```

기쁨·분노는 MVP 이후 선택 확장 지역이므로 이번 맵 제작 범위에서 제외한다. 확장 입구는
균열 클리어 허브에 실루엣과 비활성 슬롯으로만 예약하며, 본편 엔딩 진입을 막지 않는다.

## 4. 맵 드로잉 납품 단위

각 방은 다음 5장의 레이어 또는 그룹으로 분리해 공유한다.

1. `Collision`: 바닥, 벽, 발판, 위험 영역
2. `Gameplay`: 적, 기믹, 보상, 체크포인트, 복귀 앵커
3. `Camera`: 경계, 고정 앵커, 전환 구간
4. `Environment`: Far/Mid/Foreground 랜드마크와 서사 오브젝트
5. `State`: 첫 방문, 스킬 획득 후, 클리어 후 변화

한 장의 완성 그림만 공유하지 않는다. 최소한 Collision과 Gameplay는 별도 레이어로 제공해
Unity 블록아웃과 아트 배치를 같은 기준으로 비교할 수 있게 한다.

## 5. 구현 순서

```text
공통 이동·카메라 검증
→ 몽환의 우주 4방
→ 지역별 허브와 능력 성소(R/G/F 01~05)
→ 지역별 중반 이동방(06~08)
→ 정예·중간 보스(09~10)
→ 정적·지역 보스(11~12)
→ 비밀방과 백트래킹
→ 엔딩
→ 아트·사운드·최종 밸런스
```

각 지역을 완전히 끝낸 뒤 다음 지역을 시작하기보다, 세 지역의 같은 기능 방을 묶어 구현하면
공통 컴포넌트와 카메라 문제를 일찍 발견할 수 있다.

### 5.1 플레이타임 제작 목표

- `초회 15~20분`: 필수 학습·중간 시험·지역 보스를 모두 경험하는 첫 클리어 기준이다.
- `숙련 재돌파 8~10분`: 능력과 열린 숏컷을 보유하고 주 동선만 이동하는 기준이다.
- `선택 포함 25~30분`: 비밀방 3개와 선택 보상·기억 파편 탐색을 포함한다.
- `백트래킹 5~8분`: 목적지를 알고 열린 숏컷으로 특정 비밀방에 다녀오는 왕복 기준이다.

12개 메인방은 유지하되 각 방의 필수 사건을 하나로 제한한다. 긴 탐색, 두 번째 조우,
추가 보상은 옆가지로 옮겨 초회 학습 단계와 빠른 재돌파를 동시에 보존한다.

## 6. 공유 전 확인표

- [ ] 모든 연결 출구의 방향과 바닥 높이가 맞는다.
- [ ] 필수 진행, 선택 보상, 나중에 열리는 길을 다른 표기로 구분했다.
- [ ] 각 방에 긴장 또는 이완 중 주 역할이 하나 있다.
- [ ] 새 기믹을 안전하게 본 뒤 실제 위험과 결합한다.
- [ ] 낙하·피격 후 복귀 위치와 시간이 표시되어 있다.
- [ ] 보스 재도전 동선에 일반 전투를 강제하지 않는다.
- [ ] 기억 파편 ID와 위치가 `NARRATIVE_CONTENT.md`와 맞는다.
- [ ] 카메라가 화면 밖 착지나 화면 밖 공격을 만들지 않는다.
- [ ] 완성 아트가 없어도 Collision과 Gameplay만으로 테스트 가능하다.
