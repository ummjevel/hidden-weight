# 잔재 환경 이미지 생성 기록

모든 시트는 내장 이미지 생성 도구로 균일한 녹색 배경에 생성한 뒤 크로마키를 제거해
투명 PNG로 변환했다. `*_Source.png`가 생성 원본이며 Unity 적용본은
`HiddenWeight/Assets/Art/Residue/Environment`에 있다.

## 공통 프롬프트

- 2D 다크 코즈믹 호러 메트로배니아의 모듈형 전경 게임 Sprite
- 기존 잔재 아틀라스의 검은 고딕 철골, 회갈색 석재, 사슬과 거대한 뼈·손 모티프
- 낮은 앰버 이음빛과 제한적인 남색·남보라 반사광
- 균일한 `#00FF00` 배경, 그림자·바닥면·풍경·텍스트·라벨·UI·캐릭터 제외
- 각 셀은 동일한 측면 시점, 안전 여백, 독립 실루엣을 유지
- 발판 윗면은 배경보다 밝은 연속적인 가장자리로 표현

## `Residue_TerrainTiles_v2`

6×4 배열. 직선 바닥, 끝부분, 외곽·안쪽 모서리, 천장, 세로 벽, 벽 캡, 아치·기둥,
좌우 경사, 균열 바닥과 무너진 끝을 24개 독립 모듈로 생성했다.

참조:

- `Residue_TerrainAtlas.png`
- `Residue_InteractablesAtlas.png`

## `Residue_Platforms_v1`

6×3 배열. 소형 돌 발판 3종, 소형 철골 발판 3종, 중형 구조 6종, 매달린 발판 3종,
손가락뼈·갈비뼈와 철골이 결합된 발판 3종을 생성했다.

## `Residue_RewindStructures_v1`

6×4 배열. 열마다 소형 발판, 중형 발판, 사슬다리, 철문, 승강기, 도르래를 고정하고
행마다 파손, 복원, 복원 초기, 복원 후기 상태를 같은 시점과 피벗으로 생성했다.

## `Residue_Hazards_v1`

6×3 배열. 바닥·천장·벽 가시, 심연 촉수, 압착 장치, 붕괴 바닥, 낙하물을 대기·예고·공격
상태가 읽히도록 생성했다. 앰버와 남보라 밝기 상승을 위험 예고로 사용했다.

## `Residue_EnvironmentProps_v1`

6×4 배열. 기둥, 철골, 돌무더기, 사슬, 우리, 교수대, 갈비뼈, 손가락뼈, 천, 제단,
잔재 시체, 벽 부조, 봉인된 눈, 석상, 등과 균열·얼룩·재 데칼을 생성했다.

## `Residue_AmbientVFX_v1`

6×3 배열. 재·먼지, 낮게 흐르는 남색 안개, 앰버 불씨와 작은 낙하 파편을 각각 6프레임
루프로 생성했다. 반투명 가장자리를 유지하도록 크로마키 제거 시 soft matte와 despill을
적용했다.
