# PRODUCTION_20260802_PLAYTEST_CHECKLIST.md — 튜토리얼·잔재 QA

> 범위: `Zone_Prologue`, `Zone_Residue_Full`만 검수한다.
>
> 완료선: 잔재 보스 처치 후 `Zone_Gaze_Full` 전환 확인. 응시 내부는 플레이하거나 수정하지 않는다.

## 1. 실행 전

- Unity 에디터 Play Mode에서 배경음과 효과음이 모두 들리지 않는지 확인한다.
- 시작 화면에서 처음부터 시작할 수 있는지 확인한다.
- 시작 화면의 `1단계 · 잔재` 바로가기는 보스 구간 반복 QA에 사용한다.
- 플레이 중 `M`을 눌러 전체 지역 지도와 현재 방 표시를 확인한다.

## 2. 튜토리얼 T01~T04

### T01 — 이동·점프

- 배경과 실제 바닥의 경계가 즉시 구분되는가.
- 궤도 장식이 캐릭터·길·안내를 덮지 않는가.
- 이동과 점프 안내가 행동 전에 나타나고, 성공 후 사라지는가.
- `이곳은 기억과 감정이 공간이 된 꿈이다.`가 이동을 막지 않는가.

### T02 — 벽점프

- 아래 안전길에서 벽점프 굴뚝 입구를 찾을 수 있는가.
- 양쪽 벽이 배경에 묻히지 않는가.
- 손 장식이 벽과 안내 문구를 가리지 않는가.
- 실패해도 추락사나 진행 불능 없이 다시 시도할 수 있는가.

### T03 — 대시·첫 전투

- 점프와 대시를 함께 써야 하는 구간이 한눈에 읽히는가.
- 실패했을 때 아래 지형에서 복귀할 수 있는가.
- 첫 적의 스프라이트가 이동 중 잘리거나 네모난 마스크처럼 보이지 않는가.
- 공격 안내가 적과 겹치지 않는가.

### T04 — 종합

- 전투 → 벽점프 → 점프·대시 순서가 자연스럽게 읽히는가.
- 굴뚝 아래로 정상 진입할 수 있는가.
- 마지막 대시에 실패해도 계단 우회로로 올라갈 수 있는가.
- `첫 번째 공간 · 잔재` 안내 뒤 잔재로 자연스럽게 전환되는가.

## 3. 잔재 보스 구간

### R11 — 보스 직전 회랑

- 위 발판 두 개가 배경과 구분되는가.
- 점프에 실패하면 아래 안전 통로로 계속 진행할 수 있는가.
- 비밀방용 서쪽 계단과 되감기 게이트가 보스 주 동선을 막지 않는가.
- 오른쪽 끝에서 R12 진입 방향이 명확한가.

### R12 — 기억의 교수대

- 입장 직후 보스 전장이 시작되는가.
- 보스와 투사체가 배경·사슬 장식에 묻히지 않는가.
- 복원 가능한 안전 발판 두 개를 전투 중 식별할 수 있는가.
- 보스 처치 전 오른쪽 출구가 잠겨 있고 조건 문구가 보이는가.
- 보스 처치 후 `기억 파편`이 나타나는가.
- 열린 오른쪽 출구에 `다음 지역 · 응시`가 보이는가.
- 출구 접촉 후 `Zone_Gaze_Full`로 전환되는가. 전환 확인 즉시 검수를 종료한다.

## 4. 피드백 기록 형식

문제가 있으면 아래 세 항목만 기록한다.

```text
방: T02 / R11 / R12
위치: 화면 왼쪽·중앙·오른쪽 또는 보이는 오브젝트 이름
문제: 무엇이 안 보이는지, 막히는지, 너무 어려운지
```

가능하면 문제가 보이는 순간의 게임 화면 스크린샷을 함께 남긴다.
