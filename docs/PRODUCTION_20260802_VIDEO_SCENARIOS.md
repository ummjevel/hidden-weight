## 0. 공통 연출 원칙

- 플레이어가 아무 정보 없이 보더라도 다음 네 가지를 이해해야 한다.
  1. 이곳은 현실이 아니라 감정과 기억이 공간으로 변한 꿈이다.
  2. 주인공은 잃어버린 자아를 찾기 위해 꿈의 깊은 곳으로 들어간다.
  3. 여정은 지나간 것, 지금 나를 붙잡는 것, 아직 오지 않은 것을 차례로 마주한다.
  4. 목표는 감정을 없애는 것이 아니라 외면했던 자신의 일부로 받아들이는 것이다.
- 꿈 이론은 화면에 학술 용어로 설명하지 않는다. 기억의 재배열, 깨어 있는 감정의 연속,
  자각과 거짓 깨어남을 장면의 규칙으로 보여준다.
- 주인공의 현실 신원·얼굴·성별·직업은 확정하지 않는다. 작은 자아의 씨앗과 1인칭 손만
  사용해 보편성을 유지한다.
- 지역 이름과 감정의 대응을 시작 영상에서 직접 밝히지 않는다. 지역을 먼저 경험하고 의미를
  나중에 연결하게 한다.
- 영상 속 문구는 자막과 내레이션이 동일한 문장을 사용한다. 음성 없이 자막만으로도 이해돼야 한다.
- 시작 영상 마지막 프레임은 T01 시작 프레임과 최대한 일치시켜 영상 종료를 로딩처럼 느끼지 않게 한다.
- 엔딩 영상은 플레이어가 마지막 행동을 선택한 뒤 시작한다. 결말의 주체를 영상이 빼앗지 않는다.

## 1. 꿈 이론의 연출 번역

이 작품은 꿈의 기능을 하나의 확정된 과학적 사실처럼 단정하지 않는다. 아래 관점을 이야기와
이미지의 설계 재료로만 사용한다.

| 관점 | 안전한 해석 | 영상에서 보이는 방식 |
| --- | --- | --- |
| 꿈의 연속성 | 깨어 있을 때 중요했던 경험과 감정이 꿈에 반영될 수 있다. | 현실의 이름 없는 파편이 별과 폐허로 변한다. |
| 기억의 재활성화·재구성 | 수면 중 기억망의 재활성화와 꿈 내용 사이의 관련성이 연구되고 있다. 꿈이 기억을 완벽히 재생한다고 단정하지 않는다. | 같은 파편이 과거·현재·미래 위치에 동시에 나타나며 새로운 공간을 만든다. |
| 자각몽의 메타인지 | 꿈을 꾸는 중 자신이 꿈꾸고 있음을 알아차리는 상태를 자각으로 사용한다. | 플레이어가 세상의 이상을 발견하고 직접 자각을 사용한다. |
| 거짓 깨어남 | 깨어났다고 믿지만 아직 꿈인 경험을 엔딩의 첫 침실에 사용한다. | 같은 침실을 두 번 보여주되, 첫 장면에만 꿈의 규칙 오류가 남는다. |
| 개성화와 그림자 | 외면한 감정을 없애는 것이 아니라 자신의 일부로 인정한다는 작품의 심리적 은유다. | 보스가 사라진 자리에 힘이 아니라 작은 자아의 조각이 돌아온다. |

## 2. 시작 영상 — 「잠들어 남은 것」

### 2.1 제작 정보

| 항목 | 권장안 |
| --- | --- |
| 본편 길이 | 15초 |
| 화면 | 16:9, 무자막 마스터와 자막 합성본 분리 |
| 시점 | 발만 보이는 현실의 인물 → 눕는 순간 1인칭 → 뒤집힌 침실 → T01 게임 카메라 |
| 대사 | 내레이션/자막 2문장, 공백·문장부호 포함 약 37자 |
| 음악·효과음 | 음악 없이 발걸음·침대·이불 소리로 시작 → 잠든 호흡과 이불 속 저역 → 별빛 한 음 → 게임 환경음으로 연결 |
| 스킵 | 첫 실행부터 허용, 스킵 시 T01 첫 고정 프레임으로 페이드 |
| 트레일러 재사용 | 시작 영상 15초 전체를 티저 도입부로 그대로 사용 |

### 2.2 관객이 이해해야 하는 문장

> 잠들면, 남겨 둔 감정은 꿈이 된다.
>
> 눈을 뜨려면, 먼저 그 안으로.

두 문장은 현실에서 꿈으로 넘어간다는 전제와 플레이 목표만 안내한다. 과거·현재·미래는 침대
반대편에서 올라오는 세 종류의 무형 감정으로 보여주며, `죄책감`, `수치심`, `불안`, `잔재`,
`응시`, `균열`을 직접 해설하지 않는다. 플레이 후 형상의 의미가 다시 읽히게 한다.

### 2.4 친절함을 위한 연출 장치

- 세 지역 모티프는 완성된 지역 풍경이 아니라 1초 안에 생겼다 사라지는 무형의 암시로만 보여준다.
- 자막은 한 화면 최대 두 줄, 한 줄 22자 이내를 목표로 한다.
- 첫 6초의 걷기·앉기·눕기 동작을 끊김 없이 보여 추상적인 후반부의 기준점을 만든다.
- 시작 영상 뒤 T01에서 손 실루엣과 원형 궤도를 다시 보여 영상의 정보를 즉시 복습시킨다.
- 영상 스킵 여부와 관계없이 T01의 기본 조작 학습은 동일하게 제공한다.

### 2.4.1 현실음 연출 규칙

- 첫 6초는 배경음악을 사용하지 않고 발걸음, 옷감, 매트리스, 이불 소리만으로 현실의 거리와 움직임을 전달한다.
- 발걸음은 크고 무거운 구두 소리가 아닌 양말 또는 가벼운 실내화가 바닥에 닿는 부드러운 소리로 성별·연령의 인상을 최소화한다.
- 이불 스침은 1인칭 전환을 감추는 음향 매치 컷으로 사용하되, 자막과 내레이션을 가리지 않도록 고역을 줄인다.
- 새근새근 숨소리는 코골이나 특정 성별로 느껴지는 음색을 피하고, 짧고 규칙적인 중성 호흡으로 녹음한다.
- 0:06 이후에는 호흡을 갑자기 끊지 않는다. 마지막 날숨을 늘여 꿈의 저역과 섞고, 0:12의 별빛 한 음에서 완전히 사라지게 한다.

### 2.4.2 성별·신원 비공개 촬영 규칙

- 현실 인물은 무릎 위, 얼굴, 머리카락, 체형 전체를 보여주지 않는다.
- 발은 맨발보다 무채색 양말을 사용하고 잠옷은 헐렁한 직선 실루엣으로 한다.
- 방 안에는 특정 연령·성별·직업을 단정하는 사진, 교복, 화장품, 명찰, 장난감 등을 두지 않는다.
- 침대에 눕는 전환은 이불이 화면을 가리는 자연스러운 매치 컷을 사용한다.
- 시야 반전은 멀미를 줄이기 위해 눈 깜박임 암전 사이에서 0.6~0.8초 동안 처리하고,
  연속적인 빠른 180도 회전이나 카메라 흔들림은 사용하지 않는다.

### 2.5 트레일러 재사용

- 시작 영상 전체가 이미 15초이므로 별도 재편집 없이 트레일러 도입부로 사용한다.
- 게임 본편은 마지막 3초를 T01 조작권 전환에 사용한다.
- 트레일러에서는 같은 마지막 3초 위에 `Hidden Weight / 눈뜨는 꿈` 타이틀을 합성한다.
- 1분 제출 영상에서는 15초 전체 또는 0:00~0:05만 사용하고 잔재 플레이로 전환할 수 있다.

## 3. 엔딩 영상 — 「문 밖의 아침」

### 3.1 영상의 시작 조건

엔딩 영상은 25초짜리 연속 컷신이 아니라 `영상 A 12초 + 플레이 구간 + 영상 B 13초`로 나눈다.

1. `LEVEL_50_ENDING.md`의 엔딩문을 통과하면 암전 후 영상 A가 시작된다.
2. 주인공이 침대에서 눈을 뜨고 거짓 침실의 위화감을 발견한다.
3. 거울의 지연된 반사를 본 직후 조작권을 돌려준다. 플레이어가 직접 자각을 사용한다.
4. 거짓 침실을 벗어난 뒤 진짜 침실에서는 자각 입력을 놓고, 플레이어가 직접 방문까지 이동한다.
5. 방문 앞에 도달하면 영상 B가 시작된다. 주인공이 손잡이를 돌리고 방 밖으로 나가며 결말과 타이틀로 이어진다.

영상은 이상을 보여주되 정답 입력을 대신하지 않는다. 엔딩의 핵심 판단과 마지막 이동은 플레이어가
직접 수행한다.

### 3.2 제작 정보

| 항목 | 권장안 |
| --- | --- |
| 길이 | 영상 A 12초 + 영상 B 13초, 총 25초 + 중간 플레이 구간 + 크레딧 |
| 시점 | 얼굴을 보여주지 않는 1인칭 |
| 대사 | 무대사·무자막 권장. 이상 현상과 플레이 행동만으로 이해시킴 |
| 음악 | 영상 A는 거의 무음, 영상 B에서 게임 최초의 완전한 주선율 제시 |
| 색 | 영상 A는 과도하게 밝은 아침빛, 영상 B는 현실의 평범한 사물색으로 안정됨 |
| 스킵 | 영상 A·B 각각 첫 완료에서는 3초 이후 허용, 재시청은 즉시 허용 |

### 3.4 시작 영상과의 대응

| 시작 | 엔딩 |
| --- | --- |
| 침대로 걸어가 눕는다 | 침대에서 눈을 뜨고 일어난다 |
| 이불이 시야를 덮는다 | 손이 햇빛을 가렸다가 내려간다 |
| 잠든 호흡이 꿈의 저역으로 변한다 | 알람과 아침 생활음이 현실로 이끈다 |
| 시야 전체가 뒤집힌다 | 거짓 침실에서 시계와 그림자만 거꾸로 움직인다 |
| 손 모양 별자리가 멀리 나타난다 | 거울 속 손이 늦게 따라오고, 진짜 침실에서는 바로 움직인다 |
| 세 지역의 음이 따로 들림 | 세 음이 하나의 화음이 됨 |
| 발걸음이 침대에서 끝난다 | 같은 발걸음이 방문 밖으로 이어진다 |
| 이불 안으로 들어가며 현실을 떠난다 | 문손잡이를 돌리고 방 밖의 현실로 나간다 |

### 3.5 금지 사항

- “모든 감정을 극복했다”, “완치되었다”, “꿈은 기억 정리를 위해 존재한다”처럼 단정하지 않는다.
- 얼굴·나이·성별·직업·구체적인 트라우마를 새로 확정하지 않는다.
- 세 감정의 흔적을 완전히 삭제하거나 악으로 규정하지 않는다.
- 자각을 사용하지 않은 행동을 무지나 포기로 표현하지 않는다.
- 거꾸로 가는 시계·그림자와 지연된 거울은 거짓 침실에만 둔다. 진짜 침실에서 반복해 결말을 또 다른 반전으로 만들지 않는다.
- 지연된 거울 손은 갑자기 튀어나오거나 독립적으로 움직이지 않는다. 실제 동작을 1.2~1.8초 늦게 그대로 따라오는 잔상으로 제한한다.
