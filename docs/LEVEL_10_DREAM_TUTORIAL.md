> 상위 문서: `GAME_DESIGN.md`, `WORLD_MAP.md`
>

> 목표 플레이 시간: 2~4분

---

## 0. 지역 역할

몽환의 우주는 설명 화면이 아니라 플레이어가 작은 동그라미의 몸을 직접 발견하는 프롤로그다.
플레이어는 달리기, 점프, 벽 붙잡기·벽점프, 대시, 공격을 짧은 네 방에서 익힌다. 감정
스킬과 자각은 아직 사용할 수 없고, 실패는 죽음보다 즉시 재시도로 처리한다.

핵심 감정 리듬은 다음과 같다.

```text
정적 속에서 깨어남 → 몸이 움직임 → 공간을 넘음 → 처음 저항함
→ 멀리 보이던 어두운 잔재로 스스로 들어감
```

---

## 1. 설계 원칙

- 입력 안내는 화면 중앙 문장이 아니라 해당 행동이 필요한 지점 가까이 작은 아이콘으로 표시한다.
- 아이콘은 첫 성공 즉시 사라지고 메뉴의 조작 도움말에 기록된다.
- 플레이어가 움직이기 전에는 카메라·배경도 거의 움직이지 않는다.
- 새 행동은 `관찰 → 안전한 1회 → 짧은 결합` 순서로 소개한다.
- 첫 적은 2타 처치이며 플레이어를 구덩이 방향으로 밀어내지 않는다.
- 체크포인트는 T01 시작과 T04 끝 두 곳만 둔다.
- 기억 파편은 배치하지 않고 이름 없는 첫 기억을 환경 연출로만 남긴다.

---

## 2. 전체 연결과 긴장도

```text
T01 무중력의 씨앗 → T02 별 사이의 틈 → T03 기울어진 궤도 → T04 잔재의 경계 → R01
      D0                   D1                    D1→D2              D2→D0
   이동·점프          벽점프·대시             공격·결합          최종 확인·전환
```

| ID | 이름 | 핵심 재미 | 사용 액션 | 예상 시간 |
| --- | --- | --- | --- | ---: |
| T01 | 무중력의 씨앗 | 정적이 입력에 반응하며 세계가 깨어남 | 이동, 점프 | 30~45초 |
| T02 | 별 사이의 틈 | 실패해도 아래 길로 이어지는 첫 플랫포밍 | 점프, 벽점프 | 40~60초 |
| T03 | 기울어진 궤도 | 대시로 공간을 가르고 첫 적을 직접 밀어냄 | 대시, 공격 | 45~70초 |
| T04 | 잔재의 경계 | 배운 행동을 짧게 결합해 지역문을 통과 | 전부 | 40~60초 |

---

## 3. 공통 시각·사운드

- Far: 별, 성운, 아직 형태를 갖추지 않은 잔재의 거대한 손 실루엣.
- Mid: 얇은 원형 궤도와 플레이어 입력에 반응하는 빛의 선.
- Gameplay: 충돌 지형은 밝은 은백색 외곽선으로만 표현한다.
- Foreground: T01에서는 거의 없고 T04로 갈수록 어두운 파편이 화면 가장자리를 채운다.
- 이동 성공마다 환경음에 악기 한 음을 추가한다. T04 전투 완료 시 처음으로 낮은 베이스가 난다.
- 잔재 입구는 T01부터 먼 배경에 보이되, 방을 지날수록 커지고 어두워진다.

---

## 4. 방별 제작 명세

### 4.1 T01 — 무중력의 씨앗

#### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 24 × 14 |
| 난이도 / 카메라 | D0 / 한 화면 고정 |
| 입구 / 출구 | 시작 `(3, 3)` / E `(24, 3)` |
| 체크포인트 | `(3, 3)` |
| 핵심 | 이동과 점프, 세계 반응 |

```text
        별빛 ①                 별빛 ②
          *                      *
   K P ________      ___       ________ >
###############_____/   \_____############
```

#### 배치와 순서

1. 플레이어는 `(3, 3)`에서 작은 빛으로 깨어난다.
2. 2초 동안 입력이 없으면 A/D 아이콘을 `(5, 4.5)`에 표시한다.
3. `x=9~11`의 높이 1유닛 턱 앞에서 점프 아이콘을 표시한다.
4. 첫 점프 성공 시 꺼져 있던 별빛 ①이 켜지고 카메라가 아주 약하게 추적을 시작한다.
5. `x=16~19`의 2유닛 완만한 계단을 넘으면 별빛 ②와 T02 출구가 열린다.

#### 실패·변화·검증

- 구덩이, 적, 피해 없음.
- 20초 이상 정지해도 자동 이동이나 강제 컷신을 사용하지 않는다.
- 이동과 점프를 각각 한 번 성공해야 출구 가장자리의 막이 사라진다.
- 첫 플레이어의 95% 이상이 45초 안에 출구에 도달하는 것을 목표로 한다.

### 4.2 T02 — 별 사이의 틈

#### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 28 × 18 |
| 난이도 / 카메라 | D1 / 가로 추적, 굴뚝 앵커 |
| 입구 / 출구 | W `(0, 3)` / NE `(28, 15)` |
| 복귀 앵커 | `(7, 2)`, `(20, 8)` |
| 핵심 | 안전한 낙하, 벽 붙잡기와 벽점프 |

```text
                            >
                       ######
                 #   #
                 #   #  ← 폭 4 굴뚝
       ===       #   #
P ____     ______# R #
######\___/############
       하부 안전길
```

#### 지형과 순서

- `x=6~10`에 3유닛 표준 점프를 둔다. 실패하면 `y=1~2` 하부 길로 떨어져 피해 없이 합류한다.
- `x=16~20`에 폭 4유닛, 높이 8유닛의 첫 벽점프 굴뚝을 둔다.
- 굴뚝 입구에서 벽에 붙으면 벽 먼지와 Space 아이콘을 보여준다.
- 첫 벽점프 실패는 바닥 `(18, 3)`으로 복귀하며 피해가 없다.
- 굴뚝 꼭대기에서 T03의 기울어진 원형 궤도와 잔재 손 실루엣을 보여준다.

#### 검증

- 상부 점프 성공과 하부 우회 모두 15초 안에 같은 지점으로 합류한다.
- 방향키를 누르지 않고 Space만 번갈아도 첫 굴뚝을 오를 수 있다.
- 화면 전환 중 굴뚝 상단 출구가 가려지지 않는다.

### 4.3 T03 — 기울어진 궤도

#### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 30 × 16 |
| 난이도 / 카메라 | D1→D2 / 가로 추적 |
| 입구 / 출구 | W `(0, 4)` / E `(30, 4)` |
| 전투 | 이름 없는 잔영 1, 체력 2 |
| 복귀 앵커 | `(12, 3)` |
| 핵심 | 대시, 첫 공격, 행동 선택 |

```text
                    E
P _____   <4.8>   _________        ______ >
######|~~~~~~~~~~|#########________########
      R          $       첫 적
```

#### 지형과 순서

1. `x=7~12`에 폭 4.8유닛의 틈을 둔다. 점프만으로는 가장자리까지 닿지만 대시하면 안정적으로
   통과한다. 실패하면 `(7, 3)`으로 무피해 복귀한다.
2. 착지 뒤 폭 5유닛 안전 바닥에서 대시 성공을 확인하고 재화 3개로 이동선을 잇는다.
3. 이름 없는 잔영은 `(21, 4)`에서 잠든 상태로 보인다. 플레이어가 4유닛 안에 들면 깨어난다.
4. 잔영은 체력 2, 이동속도 1.5, 공격 예고 0.7초, 접촉 피해 1이다.
5. 적을 처치하거나 위 발판으로 뛰어넘어 출구에 닿을 수 있지만, T04 문 활성화를 위해서는
   공격을 최소 한 번 성공해야 한다.

#### 검증

- 대시 없이도 구덩이 가장자리에서 떨어져 즉시 복구되며 막힌 이유를 이해할 수 있어야 한다.
- 첫 적에게 맞아도 구덩이 반대 방향으로 넉백된다.
- 공격 아이콘은 적이 공격 가능 반경 1.2유닛에 들어올 때만 표시한다.

### 4.4 T04 — 잔재의 경계

#### 제작 정보

| 항목 | 값 |
| --- | --- |
| 방 크기 | 32 × 18 |
| 난이도 / 카메라 | D2→D0 / 2개 앵커 |
| 입구 / 출구 | W `(0, 3)` / E `(32, 5)` → R01 |
| 전투 | 이름 없는 잔영 1 |
| 체크포인트 | 출구 앞 `(28, 5)` |
| 핵심 | 기본 행동 종합, 지역 톤 전환 |

```text
             #   #
       E     #   #=====$
P ____===____#   #        \____ K  [잔재문] >
######~~~###############~~~##################
      R                         R
```

#### 조우 순서

1. 낮은 발판의 잔영을 점프 공격 또는 지상 공격으로 처리한다.
2. 폭 4유닛 굴뚝을 벽점프로 오르고, 3.5유닛 표준 점프를 한 번 수행한다.
3. 마지막 4.5유닛 틈은 점프+대시로 통과한다. 실패하면 `(22, 3)`으로 무피해 복귀한다.
4. 잔재문 앞 체크포인트에서 모든 튜토리얼 아이콘을 조작 도움말로 이동한다.
5. 문에 접근하면 화면의 별빛이 줄고 거대한 손 실루엣이 Gameplay 뒤로 겹쳐진다.
6. 플레이어가 오른쪽으로 직접 이동해 문을 넘으면 R01로 연결한다.

#### 이름 없는 첫 기억

문 앞에서 1.5초 정지하면 바닥의 작은 빛들이 플레이어 뒤에 원을 만든다. 텍스트나 수집 UI는
표시하지 않는다. 이 원형 배열은 세 지역 핵심 파편을 모은 뒤 엔딩 침실의 먼지 배열로 반복한다.

#### 실패·검증

- 체크포인트 이전 모든 실패는 체력 피해 없이 최근 앵커로 복귀한다.
- T01~T04 총 플레이 시간이 첫 플레이 기준 4분을 넘지 않는 것을 목표로 한다.
- 잔재문 전환 뒤 되돌아오면 T04 체크포인트부터 시작하며 튜토리얼 안내는 재표시하지 않는다.
- 자각과 감정 스킬 입력은 이 지역에서 반응하지 않고 HUD 슬롯도 숨긴다.

## 5. 구현 요구사항

| 요소 | 요구 기능 |
| --- | --- |
| 맥락형 입력 아이콘 | 행동 가능 지점, 지연 표시, 성공 후 영구 숨김 |
| 튜토리얼 진행 상태 | 이동·점프·벽점프·대시·공격 성공 플래그 |
| 무피해 낙하 복구 | 첫 학습 구간 전용 복귀 앵커 |
| 환경 반응 | 입력 성공 이벤트로 별빛·사운드 활성화 |
| 지역 전환 | T04 출구와 R01 진입 상태 연결 |
| 도움말 기록 | 배운 입력을 일시정지 메뉴에 추가 |

---

## 6. 완료 기준

- 텍스트 문장을 읽지 않아도 다섯 기본 행동을 한 번 이상 성공한다.
- 튜토리얼에서 사망하거나 긴 로딩을 경험하지 않는다.
- 새 행동을 요구하기 전에 안전한 관찰·시도 공간이 있다.
- T04는 기본 행동을 결합하지만 정밀 입력을 두 번 연속 요구하지 않는다.
- 잔재의 거대한 손이 T01, T02, T04에서 점점 커져 다음 목적지를 기억하게 한다.
- 마지막 문을 넘는 입력의 주체가 플레이어에게 남아 있다.
